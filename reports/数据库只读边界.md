# 数据库只读边界

日期：2026-10-18

## 规则

`D:\TCMAI` 下的数据库和 JSON 是**库主资产**。软件、安装器和终端用户都不得修改它们。

正常用户能写的只有运行产物目录：

```
runtime\out\      报告、CSV、TSV、任务状态
runtime\app.log   启动日志
runtime\edge-profile\
```

## 生产读取路径

本轮静态审计覆盖 `core/`、`sources/`、`conditions/`、`integration/`：

- `tcm.db`、`coconut.db` 的 SQLite 连接均使用 `mode=ro`；
- WAL 活跃时回退到 `immutable=1`，仍是纯只读；
- `formula_db.json`、`herb_aliases_map.json` 只按文本读取，没有写回路径；
- UI 只读 `runtime\out\runs.jsonl`，不提供数据库编辑接口；
- `patch_missing_herbs` 是库主侧开发工件，不在安装器 payload 中，终端用户没有入口。

另外，应用自己的实际测试只写 `runtime\out\`：

- 安装版运行报告位于 `runtime\out\20261018-104322_smiles.report.html`；
- 卸载时该目录被整体迁移，不是被用户改库；
- 原始 `D:\TCMAI\tcm.db` 收尾时仍为 2026-10-17 11:04:05，`xtb_cache` 仍为 7 个文件。

## 补库 SQL 的处置

`data\patch_missing_herbs\` 里的 SQL 只作为库主维护候选，不进入软件安装包。
如果将来确实要补库，必须由库主确认并另行备份；终端用户不需要、也不会获得执行这一步的入口。
