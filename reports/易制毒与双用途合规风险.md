# Christos 易制毒与双用途合规风险

日期：2026-10-18

> 这不是法律意见。涉及《易制毒化学品管理条例》、危险化学品管理和刑法规制时，
> 应由中国执业律师或合规顾问结合发行方式、用户范围和实际功能作正式判断。

## 一、代码里已经存在的暴露面

| 功能 | 位置 | 风险 |
|---|---|---|
| 任意目标 SMILES 的逆合成 | `integration\tcmai_bridge\ui.py` 的 `kind=routes`；`chemreact.py routes` | 可把任意目标变成路线；目标不限于中药研究 |
| 反应条件与辅助试剂 | UI 的条件档案和 `--reagents` | 可能把“候选产物”变成更可操作的信息 |
| 可购砌块集合 | `tools\retro_search.py` 的 `purchasable_blocks` | 把“理论前体”与可购买性联系起来 |
| 方剂/药材成分枚举 | `sources\formula.py`、`sources\herb.py` | 方剂数据中实际出现 `盐酸麻黄碱`，并有大量含麻黄方；成分展示本身需要边界 |
| 本地 HTTP 服务 | 8765 | 当前绑定 `127.0.0.1`，不是公网服务；风险主要在外发包、公开接口和安装包 |

软件目前没有“目标命中受控物质就拒绝”的安全闸，也没有对 `麻黄` 类成分的特殊提示或屏蔽。

## 二、风险分级

### P0：不应直接公开放出的能力

1. 任意目标 SMILES 的逆合成路线；
2. 面向公众的反应条件与辅助试剂输入；
3. 可购砌块、供应商链接或采购建议；
4. 未经过安全审查的公网 API/匿名访问；
5. 把路线结果做成可复制、可导出、可直接执行的步骤卡。

### P1：可以保留在受控研究环境的能力

1. 单味中药/方剂的成分预测；
2. 已注册研究机构的受限逆合成，配合目标筛查和审计；
3. 只展示候选反应类型、不展示可操作条件与采购路径；
4. 对 `麻黄`、`盐酸麻黄碱`、`伪麻黄碱` 等条目只显示“受控/需合规审查”，
   不输出提取、纯化、转化或合成步骤。

## 三、建议的产品处置

### 立即（公开发布前）

1. **默认关闭公开 routes 页面和匿名 routes API**，只保留开发者/受控研究环境的命令行能力；
2. 发布包不携带 `purchasable_blocks` 索引、供应商链接和反应条件增强数据；
3. 增加目标/成分安全筛查：命中受控物质或高风险前体时，拒绝给出路线，不给“部分路线”；
4. 对 `盐酸麻黄碱`、`麻黄` 等现有数据加显式风险提示，不把其当成普通药材成分静默展开；
5. 在安装说明、用户协议和 UI 中写明“仅限合规科研/教学，不得用于非法制造受控物质”；
6. 保留审计日志和版本记录，明确日志保留与访问权限。

### 后续（如确需面向外部用户）

1. 采用机构/实名或邀请制，不接受匿名公网调用；
2. 受控物质清单由律师/合规顾问确认，使用结构标识而不是仅靠中文别名；
3. 对高风险目标做人工复核和下载限制；
4. 进行渗透测试、滥用测试和应急下架流程；
5. 正式咨询中国易制毒化学品、危险化学品和刑事合规律师；
6. 若面向境外用户，另行核查出口管制、制裁和当地前体化学品法规。

## 四、当前建议

在律师审查和受控清单完成前，**Christos 公开发行版应定位为中药/方剂研究工具**：

- 不开放任意目标逆合成；
- 不提供可购试剂和采购链接；
- 不提供受控物质的路线、条件或纯化步骤；
- 本地 8765 只作为本机开发/演示入口，不作为公网服务。

## 五、P0 落地状态（2026-10-18）

已按上述 P0 做了默认安全闸：

- 公开版 `routes` 与自由辅助试剂入口返回 409；
- UI 不显示 routes 导航，辅助试剂字段隐藏；
- 内部研究需显式设置 `CHRISTOS_RESEARCH_MODE=1`；
- 安装器不打包 `purchasable_blocks`、供应商链接或数据库。
