### ★ 一个重要的验证认识 ★

```
已删 3 个文件（副本上）
语法检查：11 个通过 / 0 个失败
```

**删模块不会造成语法错误，只会造成 import 失败。**

> 所以验证剥离是否干净，**必须跑 import 扫描，不能只看语法**——
> `py_compile` 全绿也可能一运行就 ImportError。
> 这个脚本第一步做的就是 import 扫描（用 AST 分析），而不是语法检查。

### 代码量（修正后的准确数字）

我第一版统计只数了"含关键词的行"，严重低估：

| 类别 | 行数 |
|---|---|
| 纯模块**整文件**删除 | 101 + 102 + 68 = **271 行** |
| 缠结部分（关键词行估算） | 约 **75 行** |
| **合计** | **约 346 / 3324 行 ≈ 10.4%** |

> 教训：统计"某类代码有多少"时，**整文件删除的模块要按全文算，不能按命中行算**。
> `admet_cache.py` 整文件 101 行都是 ADMET，但只有 8 行含 `ADMET` 字样。
