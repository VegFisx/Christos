## 三、逐资产规则

### 1. `tcm.db`（库主库）

- 软件与安装器**只读**访问（`mode=ro`；WAL 活跃时回退 `immutable=1`）；
- 终端用户无写入口；`runtime/out/` 之外不落盘；
- 对外只允许两种形态：① 不携带数据库；② 库主签署 §五 授权书后，按授权范围（哪张表、多少行、可否再分发）随 B 档分发；
- **禁止**：把整库打进 A 档、把库内容转成 CSV 再分发、把“表结构 + 全量行”视为非数据。

### 2. `coconut.db`（COCONUT 快照）

- 上游许可已核（2026-10-18）：curated dataset = CC0，基础设施代码 = MIT；证据在 `reports/_network_evidence_20261018/`；
- 但**本地快照的版本号未确认**：对外必须写“COCONUT 快照，版本待核（导出于 2026-09-15）”，不得写“COCONUT 最新版”；
- 随包分发时必须保留 CC0 声明与来源链接；修改过的派生表需注明改动。

### 3. `formula_db.json`（爬虫库）

- 爬虫可能仍在写入：**不读内容、不算哈希、不复制**（本次盘点只记 size/mtime）；
- 任何“打包/导出”动作必须等库主明确说“爬虫结束、可以读”；
- 若将来进入 B 档，需要逐条出处分档（已有 `formula_source_tier.json` 机制）与库主授权。

### 4. 药典派生表（`chp_*.json` / `chp2025_linked.csv`）

- 版权属原出版方，**不得公开分发**，B 档也不带；
- 允许：在内部版中作为“来源可溯的排序依据”使用；论文中引用条目与限量值时注明标准版本；
- 不允许：把限量表整体作为数据集发布、或作为第三方可下载资源。

### 5. Demo 派生物

- 只含名称、物种、方剂组成、预计算产物片段；不含 SMILES 全库、不含 routes、不含砌块；
- 每条结果保留出处字段（COCONUT/TCM 前缀已脱敏为 `COCONUT:`/`TCM:`）；
- 页内已声明“预计算示例、非实时服务”；分发时不得删除该声明。

## 四、技术要求（与边界配套的机制）

1. **打包白名单**：A/B 档打包脚本只允许显式列出的路径，默认拒绝；打包后跑一次“意外文件扫描”（数据库、`purchasable`、`supplier`、`vendor`、`chp_` 前缀）。
2. **只读自检**：发布前跑 `tools/tcm_ro.py` 与 `tools/maintain_db_readonly.py check`，要求 0 个待改。
3. **访问日志**：B 档记录 `时间 / 用户 / 目标 / 命中规则 / 是否被拒`，保留期与访问权限写入协议。
4. **撤回机制**：授权可按版本撤回；撤回后已分发包不得继续更新，需发新版覆盖。
5. **哈希留档**：每次打包记录 SHA-256（本文件 §二 已给出当前值），随包发布 `SHA256SUMS.txt`。
