## ★★ 读这份文档前必看：它的口径有局限 ★★

**这份文档只回答一个问题**：对**那 10 条改过 SMARTS 的规则**，
在**SMARTS 层面**，产物变了多少。

**它没有回答（容易误读成已经回答）的问题**：

| 常见误读 | 实际 |
|---|---|
| 「新旧引擎差异 44.6%」 | ✗ 这是**论文 SMARTS vs 我的 SMARTS**，不是引擎对引擎 |
| 「整体影响是 44.6%」 | ✗ **完全没算**新增的 40 条规则、陪跑试剂修复、运行时守恒守卫、条件激活层、级联改动 |
| 「44.6% 是母体比例」 | 部分对：是「母体 × 改动规则」配对中的比例（304/682） |

**完整的新旧引擎对比请看 [新旧引擎正面对比.md](新旧引擎正面对比.md)**
（那个才是发动机对发动机，跑在真实药材上）。

### 两个数字的口径对照

| 口径 | 数字 | 出处 |
|---|---|---|
| 改动规则的 SMARTS 层面 | **304 / 682 = 44.6%** 配对有差异 | 本文档 |
| **整个引擎对引擎（同口径）** | 旧引擎 344 个产物里，**180 个被复现（52%）**，新增 440 个 | 正面对比 |
| 产物总量的变化 | 344 → **455**（煎煮）/ **620**（全规则激活） | 正面对比 |

**44.6% 是低估的**——它只看 10 条规则，而实际改动覆盖 63 条。

## 二、五类变化及其实例

### 1. 新产品出现（84 个母体）——修好了漏匹配

| 规则 | 例子 |
|---|---|
| 酰胺水解 | `10-hydroxy-methyllycaconitine` → 新增了水解后的羧酸片段 |
| 脱水 | `(-)-Epiafzelechin` → 新增了脱水产物 |
| 酮-烯醇化 | 新增烯醇式产物（丙酮型 α碳 原来匹配不上） |
| 酯水解 | `(+)-catechin-pentaacetate` → 新增乙酸片段（酚酯原来不匹配） |
| 糖苷水解 | `Acaciin` → 新增糖苷配基（酚苷原来不匹配） |

### 2. 产物消失（53 个母体）——范围被收窄

| 规则 | 例子 | 是否合理 |
|---|---|---|
| **脱甲基** | `1'-methoxy-2'-hydroxydihydromollugin` | ✅ **合理**：那是脂肪族甲氧基，本来就不该被"脱甲基" |
| 脱水 | 某三萜皂苷 | ⚠️ 需看具体结构 |
| **醌还原** | `Sennoside e`（番泻苷） | ⚠️ **见第四节，需专门讨论** |

### 3. 产物结构改变（167 个母体）——最重要的修正

**α,β-不饱和羰基水合（86 个母体）** —— 加成方向修正：

```
底物 (1E,4E)-1-(4-hydroxy-3-methoxyphenyl)-...
  旧：COc1cc(/C=C/C(=O)C(O)Cc2ccc(O)cc2)ccc1O    ← 羟基在 α碳
  新：COc1cc(/C=C/C(=O)CC(O)c2ccc(O)cc2)ccc1O    ← 羟基在 β碳 ✓
```

**缩醛水解（68 个母体）** —— 补回丢失的产物片段：

```
底物 (+)-catechin-5-O-glucoside
  旧：2 个糖片段（另一个醇整块丢了）
  新：3 个片段（含完整的苷元）✓
```

**β-酮酸脱羧（7 个母体）** —— 补回 CO₂：

```
底物 6-malonylginsenoside rd1
  旧：只有酮
  新：酮 + O=C=O [CO2] ✓
```

### 4. 一个必须修的假差异：显式氢

比对时发现论文版有些产物带**显式氢原子节点**：

```
酰胺水解，底物 (2R)-2-acetamidoglutaric acid
  论文版产物： [H]OC(C)=O       ← 分子里真的多了一个 H 原子节点
  修正版产物： CC(=O)O          ← 正常的乙酸
```

论文版 SMARTS 写的是 `[C:1](=[O:2])[O:3][H]` —— **`[H]` 会作为一个真实原子留在产物里**。
归一化显式氢后，两者其实是同一个分子。

> 这不算功能 bug，但产物 SMILES 带游离 H 节点会污染下游分析（公式统计、指纹、相似度）。

## 四、★ 我引入的一处回归，以及随之发现的论文问题 ★

### 我改的：醌还原产物改成芳香碳

| 底物 | 论文版 | 修正版 |
|---|---|---|
| 邻苯醌 `O=C1C=CC=CC1=O` | `OC1C=CC=CC1O` **C6H8O2（多 2 个 H）** | `Oc1ccccc1O` **C6H6O2** ✓ |
| 1,2-萘醌 | `OC1C=Cc2ccccc2C1O` **C10H10O2（多 2 个 H）** | `Oc1ccc2ccccc2c1O` **C10H8O2** ✓ |
| 番泻苷 E | 有产物 | **不再匹配** |

**修正版对苯醌/萘醌给出了正确分子式，但对番泻苷那类体系不再匹配。**

### 随之发现：两个版本都匹配不上蒽醌

| 底物 | 论文版 | 修正版 |
|---|---|---|
| 9,10-蒽醌 | ✗ 不匹配 | ✗ 不匹配 |
| 大黄素（蒽醌） | ✗ 不匹配 | ✗ 不匹配 |

**原因**：蒽醌的两个 C=O **不相邻**（分别在 9、10 位，中间隔着环碳），
而 SMARTS `[O:1]=[C:2][C:3]=[O:4]` 要求两个羰基**直接相连**。

> **但论文里这条规则的说明写着「丹参酮、大黄蒽醌等」。**
> **说明与实现不符 —— 这是又一处「说明比实现大」。**

### 处置

| 选项 | 说明 |
|---|---|
| 保守 | 保留修正版（苯醌/萘醌分子式正确），把蒽醌类的缺口**明确记为已知局限** |
| 补全 | 另加一条规则专门处理"两个 C=O 不相邻"的醌（如 `[O]=[C]... [C]=[O]` 跨环） |

**我倾向"保守 + 记录"**，因为：
- 修正版在它能覆盖的范围内是**正确**的，论文版是**错的**（多 2 个 H）
- 蒽醌的缺口**两个版本都有**，不是我的修改造成的
- 补全需要新的化学判断，应该让你先知道
