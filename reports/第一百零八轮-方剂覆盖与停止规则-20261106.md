## 2. 三个未命中的定性（实测，不是推断）

1. **芍药苷元酮（C17H18O6）**：单跑芍药苷 68 跳里出现 2 条同分子式产物，但结构是**半缩醛**（`CC12CC3(O)OC(O1)C1(COC(=O)c4ccccc4)C3CC21O`），文献产物是**酮**。引擎能把糖苷/缩醛水解掉，但没有「半缩醛 → 酮」。→ **表达能力边界**。
2. **苯甲醛（C7H6O）**：野樱苷单跑能生成**扁桃腈**（C8H7NO，2 条），但没有「扁桃腈 → 苯甲醛 + HCN」。→ **真规则缺口**（氰醇裂解），与第 98~99 轮 226 条缺产物同源。
3. **柴胡皂苷元 d**：引擎给出的是**柴胡皂苷元 F**（`HBIN042778`，一致），因为柴胡皂苷 a 与 d 的二维结构相同（InChIKey 前 14 位都是 `KYWSCMDFVARMPN`），差异在立体。→ **引擎不做立体化学**，F/D 无法区分；按「a→F、d→D」的文献配对，a 这一侧是通的。

## 3. 规则族覆盖（「验到什么时候算完」的口径）

已验证（文献目标 + 产物一致）的反应族，累计 **7 个**：

| 反应族 | 出处 |
|---|---|
| `hydrolysis_ester` | 乌头碱类 → 单酯型 → 醇胺型（四逆汤 4/4） |
| `hydrolysis_glycoside` | Rb1、甘草酸、甘草苷、芦丁、黄芩苷、黄芩素、汉黄芩素、苦杏仁苷、柴胡皂苷 |
| `oxidation_aldehyde` | 桂皮醛 → 桂皮酸（本轮新增） |
| `esterification_acid_alcohol` | 醋炙（辅料乙酸酯化） |
| `demethylation_n` | 槟榔碱 → 去甲槟榔碱 |
| `hydrolysis_lactone_5ring` | 狼毒 JNB 内酯开环（分子式级） |
| `decarboxylation` | 苍耳子 CATR 脱羧（分子式级） |

新增节奏：四逆汤 +1、黄芩汤 +0、甘草酸 +0、**桂枝汤 +1**、**麻黄汤 +0**、**小柴胡汤 +0**。

→ 按事先定的停止规则（**连续 2 个方不引入新族就停**），**已满足**：停止逐方验证。

## 4. 结论：不需要「把所有方剂都验一遍」

1. 验证对象是**反应类型**，方剂只是载体。7 个族覆盖了煎煮里主要的几类：酯水解、糖苷水解、醛氧化、脱羧、内酯开环、辅料酯化、N-脱甲基。
2. 之后的「新族」多半属于**场景层**（特定药材的特定转化），按 AGENTS 第〇节留到最后阶段。
3. 覆盖度写法（给论文/报告用）：「已覆盖 7 个反应族 / 共 12 个条件 profile；未覆盖的是 X、Y（场景层）」。

## 5. 已知边界（本轮新增登记）

- 引擎缺「半缩醛 → 酮」（表达能力）。
- 引擎缺「扁桃腈 → 苯甲醛 + HCN」（可补的模板缺口，需 ORD 里有对应模板）。
- 柴胡皂苷 a/d 二维同构 → 皂苷元 F/D 不可区分（立体限制，与第 89 轮结论一致）。

## 6. 踩到的一个自己写的 bug（已修，记一笔）

`F.load_seeds` 的匹配是小写比较，但「缺哪些种子」的判定用原始大小写，于是把库里存在的 `Saikosaponin d`（库里写 d 小写）、`6-gingerol` 误判成「库里没有」——第一次跑小柴胡汤时少了一个最关键的种子，等于没验到柴胡皂苷那条线。

`validate_formula_coverage.py` 里改用 `load_seeds_ci`（键名统一小写）后：桂枝汤 4→5 个种子（868 跳）、小柴胡汤 3→4 个种子（928 跳），结果才成立。
