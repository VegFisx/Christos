# 第十七轮：绝对概率判据 + 概率校准 + 拒识（原论文 OOD 切分）

> 把「反应会不会发生」从**同对内相对排序**升级为**绝对概率 + 校准 + 拒识**。
> 数据 `BH_HTE_Curated_Dataset_v20260219.csv`（27,497 行）；主标签 `labels`（正类率 0.435），`Yield>0` 作敏感性。
> 全部数字来自 `tools/hte_absolute_model.py` 在 **40 个论文 OOD split** 上的实测。

## 0. 结论先行

1. **【实测】口径**：论文 OOD 切分 = 10 iteration × 4 split = **40 个 split**（KMeans(DRFP) 12 簇，每 split 留 3 簇）；池化 274,970 行 = 27,497 × 10（每个 iteration 的 4 个 fold 恰好把全表覆盖一次）。
2. **【实测】绝对概率判据立得住**：最好配置 **HGB+F0** 池化 ROC AUC **0.8166**、AU-PR-C **0.7810**、Brier **0.1768**
   （常数 p=0.435 的 Brier 0.2458 → skill **0.28**；AP 随机基线 0.435；多数类准确率 0.581）。
3. **【实测】HGB > LR**：F0 上配对 ΔAUC **+0.0128 ± 0.0034**，**32/40** split 胜。
4. **【实测】特征集 F0 ≥ F2 ≈ F1 ≈ F3（HGB）；LR 上 F3 崩塌**：HGB F0−F2 = +0.0128±0.0060；
   LR F0−F3 = **+0.1253±0.0116，40/40 全败**。即 SB(条件 Morgan)、QM、ADD、INT(交互) **没有显著增益**。
5. **【实测】校准**：raw 概率系统性过自信（最高分箱 mean_p 0.957 vs 实际 0.890）。只用 **train 内整簇留出 25%**
   拟合校准器（test 未参与）后池化 ECE **0.0691 → 0.0336(Platt) / 0.0456(iso)**；但**逐 split ECE 平均没改善**
   （ECE_raw−ECE_platt = **−0.0220±0.0097**，仅 **13/40** split 变好），Brier 反略升 0.1768→0.1801。
   **【推断】** 池化 ECE 的下降主要来自消除 fold 间的概率尺度差，不是修正单个 OOD 簇内部的可靠性。
6. **【实测】拒识有效**（HGB+F0 raw，按 max(p,1−p) 从小到大剔除）：覆盖率 100%→20% 时保留集准确率
   **0.748→0.918**、精确率 **0.729→0.928**、保留集内召回 0.669→0.857；但 20% 覆盖只捞到全部正例的 **15.3%**。
7. **【实测·最大的坑】这个切分里有大量 source-transfer**：it0 fold1 test 有 88% 是 `JNJ HTE 2024`、fold3 有 60% 是
   `Dreher Doyle 2018`；各 Source 的 labels 率 0.070（Dreher 2014）~0.788（AZ ELN 2023）；test 先验对 train 的平均
   绝对漂移 0.092（sd 0.106）。**只看「Source 在 train 的正类率」这一无化学捷径就有平均 AUC 0.619±0.084（40 split）**，
   与论文 DRFP 基线 0.666 同量级。**【推断】** 这既是我们 0.82 远高于论文 0.65~0.67 的主因之一，也说明本报告的
   绝对概率混着先验漂移，**不能当纯化学判据**；跨 source 部署前必须重校准先验。
8. **【实测】论文基线文件被张冠李戴**：任务里说的 `results\Data_Source_best.csv`（最好 0.649）实为 **8 类「数据源分类」**任务；与 `labels` 二分类同口径的是 `results\JnJ25_False_Train_DRFP_best.csv`：rf **0.6656** / gb 0.6632 / knn 0.6519（AU-PR-C 0.639/0.628/0.628）。
9. **【实测】未标准化的 LR 大面积不收敛**：`LogisticRegression(max_iter=2000)` 触发 ConvergenceWarning 的拟合数
   F0 20/40、F1 30/40、F2 40/40、F3 40/40；加 `StandardScaler(with_mean=False)` 后 0/40，但准确率显著变差
   （F0 配对 ΔAUC **−0.0402±0.0052**，仅 1/40 胜）。**【推断】** 不中心化会放大稀有 one-hot 列近一个量级；主口径按规格用**未标准化**，标准化作为消融给出。

## 6. 坑与局限

- **source 捷径**（结论 7）：本切分的 OOD 主要是「换数据源」而非「换化学」，谈化学判据前必须先剥离先验漂移。
- **校准器跨簇不迁移**：train 内整簇留出的校准集与 test 簇分布仍不同，逐 split ECE 无系统性改善（13/40）。
  要真修可靠性需引入 test 分布的无标签先验平移（例如按 test 簇预测均值对齐）。
- **池化 vs 逐 split 必须分开报**：所有「校准明显改善」的说法在逐 split 视角都消失甚至反向。
- **LR 不收敛**：F2/F3 的 LR 数字是 lbfgs 在 2000 步被截断的结果，只能当参考。
- **未跑**：HGB 的全 train 无校准对照、`--no-jnj-train`（论文 no_jjhte_train=True）、先验平移实验 —— 同一脚本一条命令可补。
- **解析无静默失败**：QM 27,497 行全部 50 维、Morgan 0 失败、校准器拟合 0 失败；LR 收敛告警 321 次已累计入 JSON。
