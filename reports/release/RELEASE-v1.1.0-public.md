# Christos 1.1.0 公开发布说明（2026-11-26）

> 产品名：**Christos（炼膏师）**；内部包名与命令仍为 `chemreact`。
> 本版对应 GitHub 标签 `v1.1.0`；1.0.1（标签 `1.0.1`）仍保留。

> **本仓库不包含论文正文、图件与投稿材料。** 论文通过单独渠道提交，不随本仓分发。

## 一、这一版是什么

规则库、规则级证据与方剂解析层的更新。既有基准已在 2026-11-27 用当前代码重跑：正向默认 92.01%、正向基线 55.53%、逆向覆盖 94.74%/79.81%、多步路线找回 47.67%/72.33%，与论文一致；2026-10 的冻结值 82.32% 保留为历史对照。本版新增的验证单独报告，不与冻结基准混读。

## 四、已知边界

1. **没有实验室验证。** 31 条炮制留出集只是文献定性检验，样本小，且有 4 条冻结负期望被后续规则推翻。
2. **特异性缺陷。** 引擎分不清“会不会反应”，产物数是可能产物数；Mitsunobu 等宽模板在 20/20 个方剂中都出现。
3. **条件层只标注。** 不预测速率、产率或选择性；水相条件记录只说明变换在温和水相里出现过。
4. **ORD 是通用有机数据，不是中药基质。** 规则级证据说明反应可行，不说明某味药在煎煮中真走这条路。
5. **大方剂被截断。** 端到端审计每味最多 3 个成分、全局最多 18 个种子，35 味与 74 味的方剂没有跑全。
6. **论文不随本仓分发。**
