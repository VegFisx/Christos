# 第 210 轮：dev 缺口、四条通用规则与 blind3

> 目标是用 MIT 训练侧 dev 找缺口，补独立标准例，再用新 blind3 验收。
> 结果：补了 4 条通用规则，dev/blind3 都没有提升；负结果记录在此。

## 2 dev miss 的主要信号

105 个 miss 中，出现最多的表观类别：

- Boc/Cbz 保护基脱除（`C(=O)OC(C)(C)C` / `C(=O)OCc1ccccc1` 相关）；
- 磺酰化/磺酰胺（磺酰氯 + 胺）；
- 异氰酸酯 + 胺 -> 脲；
- 芳基卤 + 胺/醇的 C–N/C–O 偶联；
- 一些保护基存在下的酰胺缩合。

## 3 新增四条通用规则

均从独立标准例派生，未用 295/blind 案例拟合；全部 `unvalidated`，默认档不加载：

|---|---|
| `deprotection_boc_amine_001` | N-Boc 甲胺 -> 甲胺 + 异丁烯 + CO2 |

| `sulfonylation_amine_001` | 甲磺酰氯 + 甲胺 -> N-甲基甲磺酰胺 + HCl |
| `addition_isocyanate_amine_urea_001` | 异氰酸苯酯 + 甲胺 -> 1-甲基-3-苯基脲 |

`tools/test_dev_rules.py`：**8/8 PASS**（正例 + 负例）。

让数字好看去改模板或改 dev 集。

## 6 下一步

- 保护基脱除不是 dev 的主缺口；主缺口更像**保护基存在下的 C–N/C–O 偶联**和
  **多官能团底物上的选择性**；
- 继续补规则前，先做 **reaction class 级 dev 统计**，不要按单个 miss 补；
- 新规则保留在探索档，等独立数据证明有迁移再加默认；
- blind3 只作为第二张考卷，不再在它上面调规则。
