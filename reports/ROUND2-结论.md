## 1. ★ 定案：主引擎用 RDChiral，不用 rdkit 原生 RunReactants

第 1 轮发现"环内断键会让 rdkit 复制原子"，当时我打算手写"开环规则族"。
本轮先验证了另一条路——**RDChiral 直接解决了这个问题**：

| 底物 | 类型 | rdkit 原生 | RDChiral |
|---|---|---|---|
| 苯甲酸甲酯 | 链状酯 | 配平 ✓ | 配平 ✓ |
| 乙酸乙酯 | 链状酯 | 配平 ✓ | 配平 ✓ |
| ε-己内酯 | **环内酯** | **★凭空多出 C4H10★** | **配平 → `C6H12O3`** |
| γ-丁内酯 | **环内酯** | **★凭空多出 C2H6★** | **配平 → `C4H8O3`** |

RDChiral 会把环**正确打开成一条完整的链**，而 rdkit 返回的两个产物片段互相重叠。

### 由此砍掉了一大块计划内的工作

原计划要新写 5 条"开环规则"（内酯 / 环状缩醛 / 环状半缩醛 / 内酰胺 / 环磷酸酯）。
**现在全都不需要了** —— RDChiral 通用地处理环内断键。

### `!@` 环键约束：只是迁就 rdkit 的权宜之计，已从规则库移除

| 写法 | 链状酯 | 环内酯 | 代价 |
|---|---|---|---|
| rdkit 原写法 | 配平 | **造原子** | — |
| rdkit + `!@` | 配平 | 不匹配（正确但不回答） | **覆盖率暴跌** |
| **RDChiral 无约束** | 配平 | **配平（正确开环）** | **无** |

`!@` 的覆盖率代价（实测匹配底物数）：

| 规则 | rdkit + `!@` | RDChiral 无约束 | 倍数 |
|---|---|---|---|
| 缩醛水解 | 15 | **400** | 26× |
| 半缩醛水解 | 3 | **44** | 15× |
| 酰胺水解 | 58 | **97** | 1.7× |
| 硫酸酯水解 | 3 | 4 | 1.3× |

> 备查：若哪天真要退回 rdkit 引擎，`!@`（非环键）是唯一能止血的写法。
> `[!R]` 递归写法**会算错**（乙酸乙酯少 C1H2）；`[C:4;!R]` / `[C:4;!r5]` **直接编译失败**。

## 2. ★ 第三类规则缺陷：SMARTS 原子映射写错

RDChiral 对原子映射比 rdkit **严格得多**，它一口气揪出了 3 条规则里
rdkit 一直**静默容忍**的缺陷——而且这些缺陷会让 rdkit 产出**看似配平、实则错误**的结果。

### 三条铁律

| 铁律 | 违反时 rdkit 的反应 | 违反时 RDChiral 的反应 | 正确写法 |
|---|---|---|---|
| ① **新增原子不许编号** | 静默容忍 | `KeyError: 5`（只在特定底物触发） | 写 `[OH]` / `[O]`，**不要**写 `[O:5]` |
| ② **同一编号不能跨元素复用** | **真的把氮原子改成氧**，数值还凑巧配平 | 抛异常 | 反应物 `[N:3]` → 产物必须还是 `[N:3]` |
| ③ 产物侧编号 ⊆ 反应物侧编号 | 同 ① | 同 ① | 同 ① |

### 真实的翻车现场

**`酰胺水解`（原始写法）**
```
[C:1](=[O:2])[N:3][C:4]>>[C:1](=[O:2])[O:3][H].[N:3][C:4]
                          ^^^^^^^^ 编号 3 在反应物里是氮，这里变成氧
```
rdkit 照做了——把 N 原子改成了 O。实测产物数从修复前的 **52** 变成修复后的 **99**，
说明之前有相当一批产物是**凭空捏造的**。

**`胺氧化`（原始写法）**
```
[CX4H2:1][NX3H2:2]>>[CX3H1:1]=[O:2].[NH3]
                                ^^^^ 编号 2 同样是氮变成氧
```
这个更阴险：原子数守恒检查**通过了**（N→O 数量不变，再加一个 `[NH3]` 补回氮），
所以第 1 轮的配平审计**没能发现它**。只有 RDChiral 报错才暴露出来。

### 已写成静态检查

`schema.py` 新增 `_check_atom_maps()`，**加载规则时即拦截**，不必跑 4000 个底物才发现。

已用 6 个用例验证有效性（**一个从不报警的检查等于没有**）：

| 用例 | 检出 |
|---|---|
| 原始坏写法（产物 `[O:3]`，反应物 3 是氮） | ✓ 1 条：映射写串了 |
| 我上一轮的坏写法（新氧编号 `[O:5]`） | ✓ 1 条：新增原子必须不编号 |
| 胺氧化坏写法（`[N:2]` vs `[O:2]`） | ✓ 1 条：映射写串了 |
| 修好之后（`[OH]`） | 0 条 ✓ |
| 修好之后（`[O]`） | 0 条 ✓ |
| 正常规则（酯水解对照） | 0 条 ✓（无假阳性） |

| 静态检查通过 | 23/23 | 23/23 |

否则 CI 永远红灯、红灯就没意义了。
