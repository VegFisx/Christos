# 第 207 轮：同一分子内双底物成环（引擎层）

> 用户选择先补引擎能力，而不是继续找某一个具体大环标准例。这一轮加了
> `intramolecular` 双端模板模式：同一个分子里含两个反应片段时，切一条环外
> 单键、跑双底物反应、再把切键接回去。295 条的最后一个大环 miss 已命中。

## 1 引擎改动

### 1.1 新规则字段

```json
{
  "intramolecular": true,
  "intra_min_path": 8
}
```

- `intramolecular` 只对 **n_tpl=2** 的规则生效；
- `intra_min_path` 是最短路径的键数下限，避免和已有的短链
  `cyclization_lactam_001` 重叠；
- 这类规则不进入普通 pair/co-substrate 路径，单独走分子内分支。

### 1.2 `_apply_intra_pair`

`core/smartreact_engine.py`：

1. 在同一个分子里分别找两个 reactant template 的匹配；
2. 在两组匹配之间找最短路径；
3. 在路径内部选一条**不属于任一匹配原子**的单键；
4. 用 `FragmentOnBonds` 切开、加 dummy 保护价态，得到两个片段；
5. 对两个片段跑原来的双底物 `RunReactants`；
6. 找到切键两端的原子 map，删掉 dummy，补回切键，sanitize；
7. 产物交给原有的原子守恒守卫和 `max_products_per_pair` 截断。

只处理路径上是单键、切断后确实分成两片的情况；切不断或找不到内部键就跳过，
不猜。

### 1.3 接入两套引擎

- `SmartReactEngine._extra_results`：新增 intra 分支；`step` 的单底物早退条件、
  孤儿规则过滤都放行 intra 规则；
- `core/engine.py::apply_rule`：显式单规则调用也走同一个 helper。

## 2 新规则

`cyclization_macro_lactam_001`

```text
同一分子内：羧酸 + 质子化伯胺（铵盐）
  -> 大环内酰胺 + H2O + H+
```

- 用 `[NH3+;D1]`，只认末端铵盐，避开肽键/酰胺 N；
- `intra_min_path: 8`；
- `provenance: unvalidated`，默认档不加载；
- 不是从 295 案例反推的模板；held-out 的 `US20080070885A1` 在探索档命中，
  skeleton 与 exact 都为真。

## 7 边界

- intra helper 只在“切开一条单键能把分子分成两片”时工作；如果底物本身已经是
  环状、切一条键仍连通，会被跳过。这一轮的目标是**开链底物成环**，不是开环。
- 只覆盖羧酸 + 末端铵盐；普通中性胺的同一分子成环没有开。
- 规则仍是 `unvalidated`；要升 `cited` 需要逐条文献反应数据。
- 大环规则是通用 SMARTS，不是某个具体骨架；但 `intra_min_path: 8` 是工程阈值，
  不是文献标定值，只用于避免短链重叠。
