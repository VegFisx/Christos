## 2. 三个可证伪的实验

面对 8.1% 的覆盖率，我没有急着下结论，而是依次提出假设、设计能证伪的实验。

### 实验一：是「前沿上限」吗？

**假设**：级联有前沿上限，两个引擎采样不同 → 放大上限应提高覆盖率。

| 前沿上限 | 旧产物 | 新产物 | 共有 | 覆盖率 |
|---|---|---|---|---|
| 60 | 1675 | 2618 | 144 | 8.6% |
| 150 | 3557 | 5298 | 268 | 7.5% |
| 400 | 7026 | 12633 | 488 | **6.9%** |

**覆盖率反而降了 → 假设否证。**

### 实验二：是「分数门槛」吗？

**假设**：新级联只传播分数 ≥0.35 的产物（那是它的收敛机制），旧级联什么都传播。

| 门槛 | 新产物 | 收敛 | 覆盖率 |
|---|---|---|---|
| 0.00 | 2892 | 否 | 8.5% |
| 0.15 | 2892 | 否 | 8.5% |
| 0.25 | 2839 | 否 | 8.5% |
| 0.35 | 2489 | **是** | 8.3% |

**门槛关掉覆盖率也不变 → 假设否证。**

### ★ 实验三：是「输入顺序」吗？★

**假设**：级联的探索区域由「采样到哪些分子」决定，而采样对**输入顺序**敏感。

**同一个引擎、同一批成分，只把输入顺序打乱，跑三次：**

| | 自覆盖率 |
|---|---|
| seed1 vs seed2 | **21.9%** |
| seed1 vs seed3 | **36.3%** |
| seed2 vs seed3 | **22.3%** |

> ### ★ 假设证实，而且问题比想的严重 ★
> **同一个引擎、同一批分子，只换了个输入顺序，输出就只有 22~36% 相同。**
>
> 那么「新旧引擎覆盖率 8%」这个数字**毫无意义**——
> 两者都只是庞大可达空间的**不同随机采样**。

## 3. 根因：一行代码

```python
def _sample_frontier(products, limit, next_round):
    by_rule = defaultdict(list)
    for p in products:
        by_rule[p.rule_id].append(p)
    per_rule = max(1, limit // max(1, len(by_rule)))
    selected = []
    for items in by_rule.values():
        selected.extend(items[:per_rule])      # ← 按【插入顺序】取前 N 个
    selected = selected[:limit]
```

**插入顺序取决于输入成分的顺序** → "挑谁进前沿"变成了随机的 →
下游探索的区域完全不同。

**级联每轮只挑 60 个分子继续反应。挑谁不挑谁，决定了后面能探索到哪。**

## 6. 顺带修正了对「新旧级联差异」的理解

修完之后再想这件事：

| 层面 | 结论 |
|---|---|
| **单轮** `predict_reactions` | 新引擎产物是旧引擎的**超集**（已证：旧独有归零）—— **没有回归** |
| **级联** `find_final_products` | **两者都是"有界采样遍历"**，输出取决于采样策略。8.1% 的覆盖率**不能用来判断引擎好坏** |

**关键区别**：单轮是可穷尽的（给定底物，把该反应位点都找出来）；
级联是**有界的**（每轮只放 60 个分子进下一轮），**本质上是一个采样过程**。

> 这不是缺陷——任何有限步的级联都必须这样做，否则永不终止。
> **但它的输出必须被理解为"一个采样结果"，而不是"完备集合"。**
