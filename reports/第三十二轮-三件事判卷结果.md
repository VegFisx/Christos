## 〇、30 秒读完（三句话）

1. **能判吗？** 在这个数据集上，引擎"该出手时都出手"（正例召回 **100%**），
   但"不该出手时也出手"（负例假阳性 **90%**）。**问题不在方向层，在条件/选择性层。**
2. **能用零产率数据校准方向吗？** **不能（实测）**：ORD 的 469 条"没发生"记录**没有溶剂名、没有反应类型**；
   HTE 的 10,696 条零产率**只有一个反应类、且溶剂桶里没有"水"**。**（阴结果，省掉半天的活）**
3. **逆反应模板对能找出来吗？** **能**：实测 **101 对精确逆模板**，
   例如 `O-甲基化 ⇄ 脱甲基`、`酯化 ⇄ 酯水解`、`N-甲酰化 ⇄ 脱甲酰化`。

## 一、第 1 件：把"对不对"变成数字

**判卷答案**：`BH_HTE_Curated_Dataset_v20260219.csv`（27,497 行 Buchwald-Hartwig 高通量实验）。
聚合出 **5,752 组**底物（(芳基卤, 胺) 对），其中**组级全零率 34.6%**
（= 34.6% 的底物对，在所有试过的条件下都没出一个产物）。抽样 60 正 + 60 负，**逐对**跑引擎。

| 指标 | 实测 | 口径 |
|---|---|---|
| **正例召回**（目标产物被复现） | **100.0%**（60/60） | 正例 = 组内最高产率 ≥ 0.5 |
| **负例假阳性**（"全零"组也产出了目标产物） | **90.0%**（54/60） | 负例 = 组内所有条件产率 = 0 |
| 引擎对每对是否至少产出**任何**分子 | **120/120 都产出** | —— |

分层看，负例假阳性在各来源上都是 91%~100%（Merck 2025 是 91%，其余 100%）。

### 这个数字怎么读（三条限制，不读会误判）

1. **它测不了方向层。** HTE 全是 Buchwald-Hartwig 及同类偶联——**一个反应方向**。
   方向层对它们全部判"方向明确"，正例和负例拿到的是**同一个标记**，
   → 方向层在这个数据上**没有任何判别力**（不是它错，是数据里没有它要区分的东西）。
2. **假阳性 90% 的锅主要在条件层，而且有个技术原因**：CSV 没有逐行统一的温度/溶剂列，
   我给全部 120 组套了**同一套条件**（DMSO / 100 °C / 金属催化剂）。
   若用真实逐条条件，数字应当更好 —— 但"更好"多少**这一步测不出来**。
3. **踩过一次坑（已修，留证）**：第一次用 `--limit 400` 把 200+200 个分子**一次性**丢给引擎，
   得到"正例召回 4%"——那是假象：200×200 = 40,000 对 > `max_pairs`(4000)，**枚举被截断**，
   绝大多数组合根本没跑。改成**逐对**跑后是 100%。这跟项目里"底物数一变、能力数字就漂"是同一个坑。

**结论（本轮最重要的判断）**：
> 现有引擎在这类反应上的毛病**不是"不知道方向"，而是"不知道什么时候不该反应"**。
> 也就是说：**下一刀该砍的不是方向层，是条件/选择性层。**
> 这个结论和上一轮我从 HTE 数值里看到的一致（条件门控 AUC 0.53、负例假阳性 94.9%）。

## 二、第 2 件：零产率数据能不能校准方向判据？—— **不能**

先测"有没有信号"，再决定要不要造表。**信号不存在，所以没造表。**

| 数据 | 实测 | 为什么不能用来校准方向 |
|---|---|---|
| ORD `negative_examples.jsonl` | 449 条（notes 严格短语） | **没有溶剂字段**（溶剂桶统计为空）、**没有反应类型** |
| ORD `negative_yield_zero.jsonl` | 404 条（真实 `PERCENTYIELD==0`） | 字段只有 `cxsmiles / temperature / all_yields / notes_head`，**没有溶剂名、没有反应类型** |
| ORD `negative_clean.jsonl` | 17 条（人工复核过的） | 太少 |
| HTE `hte_negatives.jsonl` | **10,696 条**（全部产率 0） | **只有一个反应类（B-H）**；溶剂桶只有 `nonwater` 和 `unknown`，**没有 `water_like`** |

**组内对照**（HTE，5,752 组里 459 组同时含零产率和正产率）：

| 溶剂桶 | 零产率率 |
|---|---|
| unknown | 59.5% |
| nonwater | 38.7% |
| **water_like** | **样本为 0 —— 无法测** |

**结论**：想校准"**水相里酯化该不该发生**"这条判据，
现有全部负例数据里**恰好没有水相样本**，也没有反应类型标签。
→ 这不是"没做"，是**数据里没有这个信息**。
→ 若要补，只有两条路：① 找含水性介质的失败实验数据；② 做实验。

## 三、第 3 件：逆反应模板配对 —— **找出来了 101 对**

**产出**：`reports/reverse_template_pairs.jsonl`（每行一对）+ `..._summary.json`
**工具**：`tools/find_reverse_template_pairs.py`（可用 `--loose` 允许小分子补偿）

| 项 | 实测 |
|---|---|
| 载入模板 | `mined_forward` 5,670 + `mined_mono` 3,256 = **8,926 条** |
| 编译失败 | **0**（修了 SMARTS/SMILES 解析口径之后） |
| **精确互为逆模板** | **101 对**（1.1%） |
| 类型 | 全部由 `mined_forward`（双底物）⇄ `mined_mono`（单底物）组成 |

**样例**（左 = 正方向模板，右 = 它的逆）：

| 正方向 | 逆方向 | 化学含义 |
|---|---|---|
| 芳基 F + 甲醇 → 芳基甲醚 | 芳基甲醚 → 芳基 F + 甲醇 | O-甲基化 ⇄ 脱甲基 |
| 酰氯 + 甲醇 → 酯 | 酯 → 酰氯 + 甲醇 | 酯化 ⇄ 酯水解（氯代途径） |
| 甲酸 + 胺 → 甲酰胺 | 甲酰胺 → 甲酸 + 胺 | N-甲酰化 ⇄ 脱甲酰化 |
| 酚 + 甲醇 → 苯甲醚 | 苯甲醚 → 酚 + 甲醇 | 酚甲基化 ⇄ 脱甲基 |
| 乙酸 + 甲胺 → N-甲基乙酰胺 | N-甲基乙酰胺 → 乙酸 + 甲胺 | 乙酰化 ⇄ 酰胺水解 |

**怎么修的（留证）**：第一版用 `MolFromSmiles` 解析模板组分，**8,926 条全部"编译失败"**
（模板是 SMARTS，带 `;D1;+0:1` 这类查询原子）。改用 `MolFromSmarts` 后 **0 失败**，并打印骨架样例自证。

**边界**：这 101 对只说明"**两条模板在结构上互为逆**"；
**不代表**两条在当前条件下都能激活，**也不代表**方向偏好 —— 方向偏好仍由 `core/direction.py` 的判据表管。

| 问题 | 答案 | 证据 |

| 我们的判断**准不准**？ | 该反应的都能预测到（100%），但**不该反应的也说能**（90%） → 病在条件/选择性 | §一 |
