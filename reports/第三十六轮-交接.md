## 二、现在的事实（全部实测）

### 规则层（`core/smartreact_engine.py`）
* 试剂：**角色匹配**（metal_catalyst / phosphine / carbonate / alkoxide / amine / water / acid / hydride / azodicarboxylate）
  —— 只作用于"降权"那条；**"必需试剂判零"仍是严格匹配**（不放宽）
* 溶剂：有成败标签（n≥50）时按成功率奖惩；**没标签 → 中性**（信息缺失≠信息否定）
* 效果：`B-H` 的 0.5 档从 **82% 降到 ~35%**；DMSO 从被扣分 → 均值 0.804

### 规则层的判别力天花板（关键数字）
* 同组（同底物对）高产率 vs 零产率：**成对 AUC ≈ 0.51**（全量 27,497 行：0.514）
* 但方向是对的：`activation 1.0 → 成功率 56.7%`、`0.6 → 50.0%`、`0.5 → 42.4%`
* **原因不是写错，是"窗口内/外"这种二值判据给不出排序**（大量平局）

### 模型（`tools\train_condition_model.py`，**尚未接入**）
| 口径 | AUC |
|---|---|
| 常数基线 | 0.500 |
| 规则层 | 0.514 |
| GBM（条件+指纹）/ 同底物对换条件 | **0.782** |
| GBM（条件+指纹）/ **换底物对** | **0.749 ± 0.089** |
| GBM（**只用条件**）/ 换底物对 | 0.682 ± 0.032 |

* 交叉验证**按底物对分组**（`GroupKFold` / `GroupShuffleSplit`），避免同底物泄漏
* 只在 HTE（Buchwald-Hartwig 型偶联）上训练/评估；**别的反应类不能外推**

## 三、★ 下一步要用户拍板的三件事（都没做）

1. **模型算门控还是排序？** 用户已明确「打分停工」→ 它只能当**条件可行性门控**
   （判断"这套条件该不该产生这个产物"），**不能**用来给产物排序。
2. **阈值怎么定？** 保守（宁可漏判）还是激进（宁可误杀）——这决定假阳性/召回怎么换。
3. **其它反应类怎么降级？** 只有 B-H 有带标签数据。
   要么"有模型的用模型、没有的用规则"（按类降级），要么先把数据补齐。

另外两个可选方向：
* **补温度**：HTE 的 CSV **没有逐行温度**，模型缺了这个重要变量。
  可以找带温度的条件数据集，或从 ORD 的 `temperature_C` 里补。
* **补规则层的试剂角色词表**：仍有 35% 落在 0.5（`P2Et`/`KDMO`/`tAmONa` 这类缩写名认不出）。

## 四、★ 别再踩的坑（本轮踩过，都留了证据）

| 坑 | 现象 | 正确做法 |
|---|---|---|
| **批量跑被截断** | 把 200+200 个分子一次丢进 `engine.step()` → 40,000 对 > `max_pairs`(4000) 被截断，实测得到**假的"召回 4%"** | **逐对跑**（或分批，确保不超 `max_pairs`） |
| **模板当 SMILES 解析** | 8,926 条模板"全部编译失败" | 模板是 **SMARTS**，用 `MolFromSmarts` |
| **交叉验证不分组** | 同底物的不同条件跨折 → AUC 虚高（第一版 0.64） | 按 `(aryl,amine)` 分组切 |
| **拿含本组的统计打分** | 同一组内的成功记录泄漏进分数 → AUC 虚高 | 留组交叉（`leave-group-out`） |
| **关键字分类** | 用"字符串里有没有『降权』"分类依据，把"无 ORD 条件数据，放行"误判成"窗口命中" | 显式写分类器（`query_base.classify_activation`） |
| **推断当结论** | 第三十三轮初版把"无数据"写成根因，实测 37 类**全都有数据** | 先测再写（`AGENTS.md` 第 1 条，本轮实际犯过一次并更正） |
| **把统计归给"看起来像"的类** | 溶剂证据第一版同时归给 `B-H` 与 `cross_electrophile_coupling`（我以为都是偶联）→ `cross_electrophile_coupling` 在 THF 下被降权 → **撞坏 `test_required_reagent_gate` 的"37 类全放行"断言（exit 1）** | 数据只归给**实测确认**的那一类；改完**必须重跑全部门控测试**（本轮就是靠它抓到的） |
