## 1. 换个角度：查「变化量」而不只是「认不认」

上轮的探针矩阵只回答「这条规则**认不认**这个底物」。
本轮做 `tools/audit_delta.py`，回答「**认了之后，分子的变化量对不对**」。

```
对每条规则 × 每个探针，算 (产物分子式 − 底物分子式)
再跟规则类别应有的变化量比对：
    水解/水合  应 +H2O        脱水/缩合  应 −H2O
    脱羧      应 −CO2        氧化      应 +O 或 −H2
    还原      应 +H2 或 −O    加成/重排  应 Δ=0
```

**一条规则可能认得出底物、配平也没问题，但变化量跟规则名完全不符。**

## 3. ★ bug 十：脱甲基「认一切 O-CH₃」★

不过表格里有一条很扎眼：

```
【脱甲基】类别=demethylation   实际 H+2 O+1   ×6   例：甲醇
```

**"脱甲基"应该少一个碳，差值却是"加了一分子水"。** 查下去：

```
SMARTS: [O:1][CH3:2] >> [O:1][H].[CH3][OH]      co_reagents={"H2O": 1}
```

它对**任何** O-CH₃ 都生效：

| 底物 | 产物 | 真相 |
|---|---|---|
| 苯甲醚 | 苯酚 + 甲醇 | ✓ 正确的脱甲基 |
| **乙酸甲酯** | 乙酸 + 甲醇 | ✗ **这是酯水解** |
| **苯甲酸甲酯** | 苯甲酸 + 甲醇 | ✗ **酯水解** |
| **甲基葡萄糖苷** | 葡萄糖 + 甲醇 | ✗ **糖苷水解** |
| **甲醇** | 水 + 甲醇 | ✗ 无意义 |

**同一个转化被两条规则重复计算，产物的"由哪条规则产生"会指错。**

**修法**：加芳香性约束 `[c:3][O:1][CH3:2]`

| 底物 | 修后 |
|---|---|
| 苯甲醚 / 愈创木酚 / 丁香酚型 | ✓ **仍然匹配** |
| 甲醇 / 乙酸甲酯 / 苯甲酸甲酯 / 甲基葡萄糖苷 | ✗ **不再匹配** |

这正是中药里真实相关的反应（**阿魏酸 → 咖啡酸**、愈创木酚型脱甲基）。

## 4. ★★ 更值得记的：这条规则的备注里早就写了警告 ★★

修的时候才发现，它的 `notes` 里写着：

> 「⚠️ SMARTS `[O:1][CH3:2]` 过宽，会命中脂肪族甲氧基，**应加芳香性约束**。」

**写了警告，但从没修。**

> 这类 TODO 最麻烦：它在文档里躺着，看起来"已经知道了"，
> 于是没人再去看——**实际上一直没处理**。

### 所以顺手扫了一遍全库备注

```
共 6 条规则的备注里含警告/待办
```

其中大部分是**历史修复记录**（已处理，留着当说明），但捞出一条真欠账：

```
【双键加氢】⚠ 过宽，仅限流 1 个
```

**「双键加氢」的 SMARTS 是 `[C:1]=[C:2]>>[C:1][C:2]`，会加氢任何 C=C**，
目前的缓解手段只是 `max_products_per_molecule=1`（限流，不是治本）。
