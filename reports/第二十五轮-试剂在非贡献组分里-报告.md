# 第二十五轮：试剂一直在「非贡献组分」里 —— 门控复测仍净亏，但挖出一个项目级缺口

> 2026-10-12。承接第二十四轮（氧化还原气氛门控净亏，判因"试剂可得率 0%"）。
> 本轮去查根因，**发现试剂信息一直都在**；补上之后门控仍净亏，但这条发现本身价值更大。

---

## 一、探针：`reagent_*` 确实是 0%，但 `agents_mapped` 有 85.88%

| 列 | 非空率 | 内容样例 |
|---|---|---|
| `reagent_names` | **0.00%** | — |
| `reagent_smiles` | **0.00%** | — |
| **`agents_mapped`** | **85.88%**（795,182/925,943） | `CC(C)=O`（丙酮）、`C(OCC)(=O)C`（乙酸乙酯）→ **其实是溶剂** |
| `solvent_names` / `solvent_smiles` | 84.95% / 85.83% | acetone / `CC(=O)C` |
| `catalyst_names` | 16.51% | `Pd carbon` |

→ 照字面看，试剂信息"确实没有"。

---

## 二、★ 推理与证实：**NaBH₄ 的原子不进产物 → 它不算"贡献组分" → 非贡献组分就是试剂**

`contributing_components()` 只保留"映射原子 >50% 进产物"的组分。
**还原剂/氧化剂/酸/碱的原子大多不进产物**，所以带还原剂的还原反应，看起来就是"**单底物**"记录。
→ 那些**非贡献组分，就是试剂**。

**实测（抽样 60,000）**：

| 项 | 值 |
|---|---|
| 单底物记录（贡献组分=1） | 14,452 |
| **其中带非贡献组分（= 试剂）的** | **11,788 = 81.6%** |
| 非贡献组分里匹配【氢化物/H₂】模式 | 1,524 个 |
| 非贡献组分里匹配【氧化剂】模式 | 127 个 |

**非贡献组分 Top 20（这就是 ORD 的"试剂表"）**：
`[Na+]` 4111 · `[OH-]` 2856 · **`[H-]` 2537** · `Cl` 2247 · `O` 2129 · `[Li+]` 1383 · `[K+]` 1090 ·
`CF3COOH` 868 · `[Cl-]` 780 · **`[BH4-]` 766** · `[Al+3]` 689 · `CO` 565 · `HCO3-` 527 ·
**`[H][H]` 521** · `[NH4+]` 506 · THF 415 · `CO3²-` 389 · `Et3N` 330 · `EtOAc` 320 · `AcOH` 299

**→ 还原剂（NaBH₄ 766、H₂ 521、LiAlH₄）、碱（OH⁻、Et₃N、碳酸盐）、酸（TFA、AcOH）全在里面。**

## 三、复测：门控补上试剂后**仍然净亏**（五配置，1,500 条真实单底物记录）

| 配置 | 命中记录产物 | 活性（有产物） |
|---|---|---|
| A 单底物模板关 | 0.0% | 0.0% |
| **B 模板开 + 门控关** | **13.2%** | 98.3% ← **当前默认** |
| C 门控开 + 条件**无**试剂（第二十四轮做法） | 4.1% | 74.1% |
| D 门控开 + 条件**带**试剂（本轮） | 6.4% | 79.0% |
| E 门控开 + 带试剂 +「**无试剂信息不门控**」 | **7.3%** | 83.3% |

**天花板在哪（本轮诊断出来的）**：
- 记录里带试剂的有 **80.8%**，但被 `REDUCTANT_HINTS` **识别出还原剂的只有 16.9%**、识别出氧化剂的 **0.9%**。
- **识别率就是门控的天花板**：识别不到的记录，还原模板照样被"空气不允许"挡掉。

## 四、结论与决定

| 决定 | 理由 |
|---|---|
| **`mono_redox_gate` 保持默认 `False`** | 最好的门控版本（E）仍把命中从 13.2% 打到 7.3%，只换回 15 个点的"活性"（而活性不等于精度） |
| 机制与五配置数字**写进代码注释** | 免得下次有人再花一轮重试 |
| **真正的瓶颈是"试剂角色识别"，不是气氛判据** | 16.9% 识别率；【推断】可从业余统计/共现里学，而不是继续调门控 |

## 五、★ 但这条发现本身是项目级的（独立于门控）

**「非贡献组分 = 试剂」补上了本项目一直缺的一块信息**：
- 条件层（Phase 2）**从来没有试剂**——`Conditions.reagents` 一直是空的，所以"必需试剂判零"在真实数据上根本触发不了；
- ORD 条件表（925,943 行）里 `reagent_*` 两列是 0%，**但从没想过"非贡献组分"这条路**；
- 而它覆盖 **81.6% 的单底物记录**（对整个 ORD 表，非贡献组分同样普遍存在）。

→ **下一步应该做的**：把"非贡献组分"正式抽成 ORD 条件表的一个新列（如 `co_reagents`），
然后 ①重测"必需试剂判零"在真实数据上的效果 ②再谈氧化还原门控。
