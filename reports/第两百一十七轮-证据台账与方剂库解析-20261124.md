`tools/link_rule_evidence.py` -> `reports/rule_evidence_20261124.md`

用 `mined_forward_templates_full_lf.jsonl`（282,704 条 ORD 模板）做三级匹配：

| 级别 | 含义 | 规则数 |
|---|---|---:|
| exact | 规范化 SMARTS 完全相同（含反向） | 0 |
| skel | 去掉原子属性后骨架相同 | **2** |
| weak | 仅子串包含 | 0 |
| none | 无同款 ORD 模板 | 71 |

两条骨架命中的是
`addition_isocyanate_amine_urea_001`（ORD support 765）与
`sulfonylation_amine_001`（support 1）。

**口径说明**：这只回答「ORD 里有没有同款变换」，不回答
「这条规则本身在 ORD 里被执行过多少次」。后者要逐条套 90 万条反应，
成本高，本轮不做。所以**没有据此改 provenance**。

## 2 文献核对（Crossref）

`tools/build_rule_literature_index.py` -> `reports/rule_literature_20261124.md`

rules.json 的 notes 里共 8 个 DOI。逐条走 Crossref 核对元数据：

| 规则 | DOI | 核对结果 |
|---|---|---|
| `coupling_suzuki_biaryl_001` | 10.1021/cr00039a007 | ✅ Chem. Rev. 1995，标题相符 |
| `coupling_sonogashira_aryl_alkyne_001` | 10.1016/S0040-4039(00)91094-3 | ✅ Tetrahedron Lett. 1975，标题相符 |
| `coupling_n_arylation_amine_001` | 10.1021/ja00105a051 | ❌ 解析成「超分子氢键聚集体」，**DOI 错了** |
| `cyclization_larock_indole_001` | 10.1021/jo00009a020 | ❌ 解析成「高自旋 π 体系电子交换」，**DOI 错了** |
| 四条环化规则 | 10.1007/978-3-030-50847-0 | ⚠️ Crossref 查不到（书级 DOI） |

**两个错 DOI 是本轮实测发现的**，已在报告里标出；按规则冻结，
**没有改 rules.json**，留给用户决定是否更正 notes。
（2026-11-24 用户授权后已在第 218 轮更正，见
`第两百一十八轮-DOI更正与同义词接入-20261124.md`。）

另外对 8 条高用量无引用规则做了 Crossref 关键词检索，每条给 3 个候选
（`rule_literature_20261124.json` 的 `candidates`）。它们**没读过原文**，
只能算候选，不是证据。

结论：73 条里目前**只有 2 条**有可核对的 DOI；证据补齐是大工程，
不能靠自动检索把候选写成 `cited`。下一步要么逐条读文献，要么
先做「规则 -> ORD 实际执行次数」的逐条套用（成本高但可自动化）。

## 3 方剂库解析

`tools/audit_formula_db_coverage2.py`

严格口径与旧版一致（81.6%），新增安全归一化：

1. 去私用区/损坏字符（`芎<U+E840>`）；
2. 去中文数字剂量（`甘草半`、`各二两`）；
3. 去炮制前缀（炙/炒/煅/醋/酒/姜/盐/蜜/生/熟/法/清…）；
4. 去形态后缀（片/条/段/块/个/只/枚/丝）。

候选只有在**命中 tcm.db 现有名称/别名**时才采用，不做模糊匹配，
所以不会凭空认错药。

| 口径 | 成分提及 | 全解析方剂 |
|---|---:|---:|
| 严格（旧） | 81.6% | 35.8% |
| 归一化 | **85.13%** | **42.93%** |
| 归一化（剔除明显辅料） | **85.54%** | **44.32%** |

明显非药材成分（硬脂酸镁、糊精、水杨酸甲酯、苯甲酸钠等）共 567 次提及，
单独计数，不混进「药材解析率」。

剩余大头是**同义词**，解析规则解决不了：

| 未解析 | 次数 | 说明 |
|---|---:|---|
| 生地 | 336 | 应为生地黄（tcm.db 里是干地黄的别名） |
| 黄耆 | 334 | 黄芪的古代写法 |
| 麦门冬 | 194 | 麦冬 |
| 桂心 / 官桂 | 255 | 肉桂 |
| 胆星 | 75 | 胆南星 |
| 炙草 | 73 | 炙甘草 |

这些要有**权威同义词表**才能补；手写一张表等于自己造数据，
本轮不做。先把口径和清单留在这里。

（第 218 轮已接入用户自己的同义词资源，推荐口径 84.97% / 42.81%，
详见 `第两百一十八轮-DOI更正与同义词接入-20261124.md`。）
