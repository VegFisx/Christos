## 3. ★ 又抓到 4 个真 bug ★

### bug 四：α,β-不饱和羰基水合 —— 加基因接错原子（第 3 次）

```
SMARTS: [C:1]=[C:2][C:3]=[O:4] → [C:1][C:2]([OH])[C:3]=[O:4]
                                            ^^^^^^^^ 羟基因在 α碳
正确:   → [C:1]([OH])[C:2][C:3]=[O:4]       因在 β碳
```

α,β-不饱和羰基水合是 **Michael 型加成**，水加到 β碳。

| 底物 | 修前 | 修后 |
|---|---|---|
| 丙烯醛 | `CC(O)C=O`（乳醛）✗ | **`O=CCCO`（3-羟基丙醛）** ✓ |
| 2-丁烯醛 | `CCC(O)C=O` ✗ | **`CC(O)CC=O`（β-羟基醛）** ✓ |

> **这是「加基因接错原子」的第 3 次**（前两次是 Michael 硫醇、Michael 胺）。
> 共同特征：`[C:1]=[C:2][C:3]=[O:4]` 里 C1 是末端、C2 是 α、C3 是羰基碳——
> **写 SMARTS 时很容易把新基团挂在"看起来更靠中间"的 C2 上。**

### bug 五：醇醛缩合 —— 氢数写死（乙醛做不了）

```
[CX3:1](=[OX1:2])[CX4H2:3].[...]   ← 要求烯醇碳恰好 2 个氢
```

乙醛的 α碳是 CH₃（3 个氢）→ **最经典的「乙醛自身缩合」这条规则做不到。**

去掉氢数限制后：乙醛+乙醛 → **`CC(O)CC=O`（3-羟基丁醛）** ✓

### bug 六：酮-烯醇化 —— 同一个氢数毛病（丙酮做不了）

```
[CX3:1](=[OX1:2])[CX4H2:3]   ← 丙酮的 α碳是 CH₃ → 匹配不上
```

修后：丙酮 → **`C=C(C)O`（烯醇式）** ✓，乙醛 → `C=CO` ✓

### ★★ bug 七：醌还原 —— 产物没芳香化，靠"灌试剂"把账凑平 ★★

```
SMARTS:  [O:1]=[C:2][C:3]=[O:4] → [OH:1][C:2][C:3][OH:4]
co_reagents = {"H2": 2}
```

**碳氧双键变单键后，C2/C3 各补 1 个氢：**

```
底物邻苯醌 C6H4O2  +  co{H2:2}(=4个H)  =  左 C6H8O2
产物        C6H8O2 +  by{}            =  右 C6H8O2   → 校验器判「配平」 ✓
```

**账是平的，但账目是假的。**

- 邻苯醌 → 邻苯二酚是 **2 电子还原，只需 1 个 H₂**
- 产物应该是**芳香**的邻苯二酚 **C6H6O2**，不是环己二烯二醇 C6H8O2
- 规则靠把试剂从 1 个 H₂ 灌到 2 个 H₂，让等式成立

**修法**：产物改成芳香碳 `[c:2]`/`[c:3]`，让 RDKit 自动芳香化；试剂恢复 1 个 H₂。

| | 产物 | 分子式 |
|---|---|---|
| 修前 | `OC1C=CC=CC1O` | C6H8O2（非芳香）✗ |
| **修后** | **`Oc1ccccc1O`** | **C6H6O2（邻苯二酚）** ✓ |

## 4. ★★ 一个反复出现的失败模式：「靠灌试剂凑平」★★

这是本项目**第三次**遇到：

| 次数 | 规则 | 手法 |
|---|---|---|
| 1 | 美拉德简化 | `by={H2:1}` 伪装成脱氢（实为氧化） |
| 2 | 分子内脱水成醚 | `by={H2:1}` 填平一个 O-O 键的结构错误 |
| 3 | **醌还原** | `co={H2:2}` 把 4 电子还原伪装成 2 电子 |

### 为什么四道闸门全都发现不了

> **校验器的判据是「底物原子 + co原子 == 产物原子 + by原子」。**
> **把 co 调大，左边就变大，等式自然成立。**
>
> **它只保证「账平」，不保证「账目真实」。**

**这正是原子守恒校验的根本局限**——它是必要条件，远不是充分条件。

**已加扫描**：`co_reagents`/`byproducts` 里单次用量 ≥2 的规则会被列出复核。修完醌还原后**归零**。
