# 第 213 轮：多标准例族模板的第一个正结果

> 这轮不再加单例子模板，改成“同一子类多个标准例取共同反应中心”。
> 氯代族成功把 dev 从 195 推到 197；N-烷基化/O-酰化的族模板还没有
> 达到 dev 的底物环境，没有硬加。

## 1 氯代族

`substitution_alcohol_thionyl_family_001`

标准例：

- 乙醇 + 亚硫酰氯 -> 氯乙烷 + SO2 + HCl
- 苄醇 + 亚硫酰氯 -> 苄氯 + SO2 + HCl
- 环己醇 + 亚硫酰氯 -> 氯环己烷 + SO2 + HCl

模板把醇碳泛化为 `[C;H1,H2,H3]`，不再要求乙基。

## 2 效果

| 集合 | 加规则前 | 氯代族后 | 再加 N-苄基族 |
|---|---:|---:|---:|
| dev full_lf | 195/300 | 197/300 | **198/300** |
| dev curated | 4 | 6 | **7** |
| dev exact | 195/300 | 197/300 | **198/300** |

氯代族提升来自两个真实 dev C–Cl 例子（`dev_0122` 苄醇型、`dev_0139`
杂环醇型）。N-苄基/杂芳甲基 N-烷基化族补上了 `dev_0016`，再 +1。
两个提升都不是改口径。

## 3 N-苄基/杂芳甲基 N-烷基化族

`coupling_n_alkylation_benzyl_001`

- 标准例：苄基氯 + 甲胺 -> N-甲基苄胺 + HCl；
- 胺侧泛化为任意碳取代（`[#6]-NH2`），氯代侧保持苄基/杂芳甲基；
- `bidirectional: true`，dev 的“胺在前、氯代在后”顺序也能命中；
- 补上 `dev_0016`，dev 197 -> 198。

## 4 没加的族

尝试了戊二酸酐 + 乙醇（O-酰化族）。模板在 dev 的环状酸酐上仍然
0 命中，所以没有加。O-酰化还需要真正处理环状酸酐/芳基酯的模板，
不适合用一个开链酸酐标准例硬套。

## 8 边界

- 新族规则仍是 `unvalidated`，默认档不加载；
- 只覆盖醇 + 亚硫酰氯；其他氯代试剂（SOCl2/POCl3/Cl2）没有混在一个模板里；
- dev 的 +2 是 dev 结果，不是 blind 结果；blind4 没有用这轮规则重跑；
- 下一次要新的 blind5 才能给这套族模板做干净验收。
