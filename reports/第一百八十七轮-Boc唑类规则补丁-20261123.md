# 第一百八十七轮：Boc 唑类规则补丁

> 用户要求：补规则，必须合理、有依据、能生成正确产物。
> 本轮只加 **1 条**新规则 `protection_boc_azole_001`；既有规则未改。
> 选择依据：295 外部探针的 class 5 miss 中有 3 条是唑类 N–H 的 Boc 保护，
> 同一类反应重复出现，且是通用保护基化学，不是为单个案例写分支。

## 1 规则

| 字段 | 内容 |
|---|---|
| id | `protection_boc_azole_001` |
| 反应 | 唑类/芳香 N–H + Boc2O → N-Boc + t-BuOH + CO2 |
| SMARTS | 见 `rules/rules.json`；反应物为 Boc2O + `[a]:[nH]:[a]`，主产物为 N-Boc，`byproducts` 记 `C4H10O`/`CO2` |
| 条件档 | `ambient` |
| provenance | `cited` |

### 1.1 依据

- 盛春泉、张万年、徐辉等，《4-[4-(5-氧代-1,5-二氢-[1,2,4]三唑-4-基)苯基]哌嗪-1-羧酸叔丁酯的合成工艺改进》，中国药物化学杂志 2006, 16(3): 159–164；Boc 保护用于三唑类中间体合成。
- CN112135825A：Boc2O/DIPEA 对咪唑并吡啶甲基胺的 Boc 保护实例。
- 通用性：Boc2O 对伯胺、仲胺、咪唑、吡咯、吲哚等 N–H 的保护是标准保护基化学；本规则只覆盖**芳香 N–H（唑类/吲哚型）**，不碰脂肪胺。

### 1.2 模板来源

用 **1H-咪唑/吡咯 + Boc2O** 的标准例子经 RXNMapper 原子映射 + RDChiral
模板抽取，再把局部环环境泛化为 `[a]:[nH]:[a]`（芳香原子，不限定某个唑）。
**没有用 30/295 外部探针案例拟合模板**；外部 3 条只作为 held-out 验证。
