## 方案 A：极简"三步走"页（推荐先做）

```
┌────────────────────────────────────────────────────────────┐
│  chemreact · 药材反应预测                                    │
│                                                            │
│  第 1 步  选药材：  [甘草 ×] [黄芪 ×] [＋ 添加]              │
│           每味取几个成分： [12 ▾]                            │
│                                                            │
│  第 2 步  条件与轮数： 条件档案 [煎煮 ▾] · 轮数 [1 ▾]        │
│           （轮数由你掌握；轮数越多产物越多越慢）              │
│                                                            │
│  第 3 步      [ 开始预测 ]                                   │
│                                                            │
│  ── 结果页（一页报告）──                                     │
│  汇总条： 产物 48 个 · 出处 48 条 · 用时 2.4s                │
│           方向：24 可疑 / 24 未定 | 条件：50% 无数据放行      │
│  ┌ 产物清单（可按方向/反应类型分组查看，仍不排序）─────────┐ │
│  │ [方向可疑▾] 反应类型 产物(分子式) 出处 条件依据 → 详情  │ │
│  │  esterification  C84H122O31  甘草  降权/窗口 …          │ │
│  │ ………（每行点开看完整出处与每一步）                     │ │
│  └──────────────────────────────────────────────────────┘ │
│  [导出 CSV/TSV]  [打开台账文件]  [再跑一轮（在此结果上加轮）] │
└────────────────────────────────────────────────────────────┘
```

**特点**：一页完成"选→跑→看"；高级参数（试剂、三组分、黑名单）折叠在"更多选项"里；产物分组只是**展示层折叠**，不改排序。

## 方案 B："实验室工作台"样式（两个标签页）

```
标签页 1：预测产物（药材 → 产物）       标签页 2：找路线（目标分子 → 路线）
┌──────────────────────────┐          ┌──────────────────────────┐
│ 左侧：药材/成分列表(可编)  │          │ 目标： [SMILES/画图]       │
│ 右侧：运行参数(轮数/条件)  │          │ 口径：○通用 ○受限池(上传)  │
│ 底部：结果表格(同方案A)    │          │ 结果：路线卡(每步带标记)   │
└──────────────────────────┘          └──────────────────────────┘
```

**特点**：两个功能分区清楚；适合以后扩展到"方剂批量"。**成本更高**（等于两套界面）。

## 方案 C：报告优先（先不做界面，先做"报告生成器"）

不点按钮：你还是命令行跑（`chemreact.py predict ...`），它自动把 `out\` 里的 CSV 渲染成
一份**图文报告（HTML/PDF）**：摘要条 + 分布图 + 可分组长表 + 附录（判据口径）。

**特点**：最省工，立刻能用；适合你"先看报告、界面以后再说"。以后加界面时，报告代码直接复用。

---

## 无论选哪个都要定的 4 个小问题

1. **产物清单怎么读**：按"方向"分组（如上）还是一张平表 + 过滤框？（都不排序）
2. **默认条件档案**：固定"煎煮"，还是每次让你选？（候选：煎煮 / 室温水 / 乙醇回流 / 自定义）
3. **"在哪看"**：先独立小窗/浏览器页，还是直接进 TCMAI 的 launcher 菜单？（接 TCMAI 要多一步）
4. **结果留在哪**：`chemreact\out\`（现在这样）还是你在 TCMAI 里指定一个"实验记录"目录？

（我的建议：C 的报告生成器 + A 的三步页，两个都做，先 C 后 A——C 半天能出，A 再一两天。）
