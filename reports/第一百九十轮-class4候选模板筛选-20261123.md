# 第一百九十轮：class 4 候选模板筛选（未加规则）

> 继续按 class 4 杂环类型筛规则。结论：**本轮没有新增规则**。
> 原因不是没找到反应，而是模板要么不能泛化到 held-out，要么配平/电荷不干净，
> 不符合“合理、有依据、能生成正确产物”的标准。

## 1 试过的候选

### 1.1 Corey–Chaykovsky 环氧化

- 标准例：二苯甲酮 + 三甲基硫叶立德 → 二苯基环氧乙烷 + 二甲硫醚。
- 模板在 held-out `US08497294B2` 上能生成正确环氧化物。
- **未加入**：输入 `C[S+](C)C` 是锍盐/叶立德前体，真实反应需要碱去质子化；
  模板主产物 + 二甲硫醚的分子式配平会差一个 H/电荷，需要额外建模碱。
  硬加会把“未建模的碱”藏进规则里，不符合配平要求。
- 依据：山东化工 2024, 53(16):82–84（硫叶立德环氧化工艺）；现代农药 2016(6)；
  化学学报 2000, 58(4)（硫叶立德立体控制环氧化）。

### 1.2 Hantzsch 噻唑

- 标准例：α-溴代苯乙酮 + 氨基硫脲 → 2-肼基-4-苯基噻唑 + HBr + H2O。
- 模板在 held-out `US20090247567A1` 上 **0 产物**：标准模板要求
  `Br-CH2-C(=O)-[c]`（溴甲基芳酮），而该案例是环状二级 α-溴酮，局部环境不匹配。
- **未加入**：为它单独写一个环状溴酮模板会变成单例拟合。
- 依据：材料导报 2012(1)《噻唑衍生物的合成研究进展》；中国药物化学杂志
  2006(4):229–232（α-溴代酮 + 硫脲，收率 87.4–98.9%）。

### 1.3 Fischer 吲哚

- 标准例：苯肼 + 苯乙酮 → 2-苯基吲哚 + NH3 + H2O。
- 模板在 held-out `US20050261331A1` 上 **0 产物**：苯乙酮的甲基/苯肼的苯环
  局部环境太窄，外部案例是苄基酮 + 杂芳基肼。
- **未加入**：泛化到杂芳基肼/苄基酮需要重写模板，已接近为单例设计。
- 依据：Fischer 吲哚是经典命名反应；但本轮没有找到可直接泛化的中文模板依据。

### 1.4 吗啉双烷基化

- 反应：苯胺 + `BrCCOCCBr` → N-芳基吗啉 + 2 HBr。
- 模板派生结果是 **3 个反应物**（两个 Br 片段 + 苯胺），当前引擎只支持 1–2 个
  反应物，不能直接入库。
- **未加入**：需要先扩展引擎的三反应物支持，不是一条规则能解决的。

## 3 下一步选项

1. **扩引擎三反应物**：支持吗啉双烷基化等真正三组分反应（框架层，优先）。
2. **为环氧化引入碱/叶立德前体建模**：先补 `co_reagents` 与配平，再入规则。
3. **从 ORD/文献派生更通用的 α-卤酮/杂芳基肼模板**，而不是按单例写。
4. **暂不补 class 4**，保持当前规则库，避免为 9 个单例堆 9 条窄规则。
