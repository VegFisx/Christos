# 第一百五十二轮：排序改进 —— 模板先验特征（负结果）

> 一句话：模板先验（命中率 + 出现次数）在内部切分把 top-1 从 0.7801 抬到 **0.8175**（+3.7 pp，3 seed 稳定），
> 但在官方 4,993 条上从 72.62% **崩到 26.44%**——**不迁移，不采纳**，默认仍是 v2。
> 顺带量化：官方测试集与本仓 12k 训练集重叠 **11.7%**，对 v2 的影响是 **−0.43 pp**。

## 1 实验设计

在候选级基准表（第 151 轮）上，同一 train/test 切分（按 `want` 的 md5）、同一超参
（HistGBM 300 轮 / lr 0.06 / 31 叶），逐个加特征组：

| 组 | 内容 |
|---|---|
| cheap | `log_n_cand` / `rank_norm` / `dup_count` / `n_tpl_same` / `n_rule_same` / `first_rank_same` |
| tan | 产物与底物的 Morgan 相似度（r=2, 2048）+ 指纹位数 |
| vote | `tpl_hitrate`（模板在训练集候选里的命中率，alpha=20 平滑）+ `tpl_hitrate_n` |

## 2 结果（内部测试 5,584 反应）

| 特征 | top-1（3 个种子） | 结论 |
|---|---|---|
| base 59 维 | .7801 / .7817 / .7844 | 模型自身波动 0.4 pp |
| +cheap | .7846 | +0.45 pp，基本无效 |
| +tan | .7804 | +0.03 pp，无效 |
| +vote | .8170 / .8204 / .8202 | **+3.7 pp** |
| +打乱标签的 vote | .7935 / .7813 / .7885 | 噪声 |
| +纯随机两列 | .7711 / .7761 / .7756 | 变差 |

**两个特征作废**：

1. **重复票**（`dup_count` / `n_tpl_same`）恒为 1——生产端 `core/smartreact_engine.py:1926`
   已按 canonical SMILES 去重。又一次「先看生产取数逻辑」的教训（AGENTS §11.10）。
2. **Tanimoto** 对 top-1 没有贡献。

## 3 模板先验：内部有效，但只是「同配置内」有效

消融（seed 0）：`cnt` 单独 .8080、`hitrate` 单独 .8023、两者 .8170。
训练时按模板整体做 dropout（50%），是为了让模型见过「统计缺失」的分支。

| 模型 | 内部测试 | 掩蔽 36% 候选（模拟官方） |
|---|---|---|
| 无 dropout | .8170 | .6538 |
| dropout 50% | .8177 | **.8071** |

内部看，这个特征又稳又有效。

## 4 官方 4,993 条：崩了

| 配置 | top-1 | top-5 |
|---|---|---|
| 不排序（发射序） | .4328 | .6777 |
| **v2（现行默认）** | **.7262** | **.8906** |
| v3（无 dropout） | .1766 | .5279 |
| v3 + 模板 dropout | .2644 | .5349 |

诊断（`_diag/probe_v3_official_shift.py` / `probe_simple_official.py`）：

- 官方候选只有 **64.1%** 的模板在训练统计里（内部测试是 99.5%）；
  官方最常见的模板（303/2,129）就是 OUT。
- 裸 `tpl_hitrate` 排序在官方 300 条上只有 **45.3%**，只比发射序高 2 pp。
- 基础特征也在漂移：`ext` 偏移 1.56σ、`log_sup` 0.89σ（官方用 curated 模板 + 严格氧化还原门）。
- 根因不是统计缺失本身，而是**训练集与生产用的不是同一套引擎配置**：
  `rank_dataset_v2` 用默认配置建，官方基准用 CLI 配置（`use_curated_templates` +
  `strict_redox_gate`）。模板的「历史命中率」在这个配置下不成立。

**结论**：模板先验特征只在「同一引擎配置 + 同一语料」内有效，**不跨配置迁移**。
默认仍用 v2；v3 只作为实验资产保留。

## 5 官方测试集与训练集的重叠（重要，与 v3 无关）

`_diag/probe_official_overlap.py` + `_diag/analyze_official_clean.py`：

| 口径 | 数量 | 占官方 |
|---|---|---|
| 官方产物在本仓 50k 语料里 | 4,997 / 4,997 | **100%** |
| 官方产物在 12k 数据集里 | 1,147 | 23.0% |
| 官方产物在 **12k 训练半集**里 | **584** | **11.7%** |

影响（`top-1`）：

| 配置 | 全部 4,993 | 去污染 4,409（剔 584） |
|---|---|---|
| 不排序 | .4328 | .4307 |
| v2 | .7262 | **.7219** |

即论文/交接单里的 **72.62% 高估了约 0.43 pp**；召回 92.19% 不受影响
（模板库挖自 ORD，与本仓 USPTO 测试集无重合，见 `tools/analyze_leakage_support.py`）。
建议论文补一句口径：官方 4,993 中有 11.7% 出现在重排序器训练集，剔除后 top-1 72.19%。
