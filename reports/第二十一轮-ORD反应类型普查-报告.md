# 第二十一轮：ORD 反应类型普查 —— "补对化学"这条路有多少原料？

> 2026-10-12。承接第二十轮的发现：**SmartReact 的 37 类全是合成偶联化学，没有水解/氧化/还原/糖苷化/美拉德**，
> 而煎煮的化学恰恰是这些。本轮量化：**这些化学在 ORD 里到底有多少原料？**
> 脚本 `tools/ord_reaction_type_census.py`；数字为**抽样 100,000 条【实测】**（全量在跑，见 §四）。

---

## 一、为什么只能这么测

ORD **没有 reaction_class**（第十八轮实测：标识 100% 是 `REACTION_CXSMILES`，`provenance.reaction_metadata` 全空）。
所以按**元素收支**反推：`Δ = Σ产物元素 − Σ反应物元素`

| 类别 | 判据（写死在脚本里） |
|---|---|
| 水解/水合 | ΔH=+2, ΔO=+1，其余元素 0（= 加了一分子水） |
| 脱水缩合 | ΔH=−2, ΔO=−1（= 脱了一分子水）**← 酯化/酰胺化/糖苷化都落这桶** |
| 氧化 | ΔO≥+1 且 ΔH≤0；或 ΔH=−2 且 ΔO=0（脱氢） |
| 还原 | ΔH≥+2 且 ΔO=0；或 ΔO≤−1 |
| 脱羧 | ΔC=−1 且 ΔO=−2 |
| 取代/偶联 | ΔC=0 且非上述 |
| 其它 | 未归类（含多步/保护基/成盐等） |

### ★ 口径修正（第一版我错了，记下来）
第一版用"**组分 ≤2**"清洗，**丢掉了 65% 的记录**。但**水解反应的典型写法就是"底物 + 水 + 酸/碱"三个组分**
——也就是说我把要找的那一类**系统性排除**了。
改为：**剔除小分子组分（重原子 ≤6；第十八轮实测 96% 的误标碱/试剂都属于这类）后，剩余组分 ≤2**。
→ 可用记录从 34,984 升到 **78,043（78%）**，其中 **43,161 条正是被救回来的**。

## 二、结果（★ 全表 925,943 条，可用 722,107 条，耗时 441.8 s【实测】）

| 类型 | 计数 | 占比 | 其中产物重原子≥25 |
|---|---|---|---|
| 其它（未归类） | 436,150 | 60.4% | 176,259 |
| 取代/偶联 | 176,159 | 24.4% | 78,632 |
| **还原** | **54,510** | **7.5%** | 17,499 |
| **脱水缩合**（酯化/酰胺/糖苷化…） | **25,213** | **3.5%** | 15,109 |
| 异构化/无收支 | 17,453 | 2.4% | 11,337 |
| **氧化** | **8,641** | **1.2%** | 2,543 |
| 脱羧 | 2,104 | 0.3% | 671 |
| **水解/水合** | **1,877** | **0.3%** | 839 |

**★ 脱水缩合里，两个组分"都像糖"的（≈糖苷化原料）：只有 56 条（占脱水缩合 0.2%）。**

**★ 敏感性（宽松口径，含成盐式水解 ΔO=+1 且 ΔH≥1）**：抽样 100,000 条上有 **333 条 = 0.4%**
（主判据同批为 206 = 0.3%）→ 全表量级 **~2,000~3,000 条**。**结论不因口径放松而改变。**

丢弃分类（全表）：`有效组分>2` 201,218 · `剔除小分子后无组分` 2,599 · `组分解析失败` 19

## 三、结论（对"煎煮/天然产物"这个目标是决定性的）

| 我们缺的化学 | ORD 里有多少原料（全表） | 判断 |
|---|---|---|
| **水解** | **1,877 条（0.3%）**；宽松口径 ~2,000~3,000 | ❌ **几乎没有**。而苷类水解正是煎煮化学的核心 |
| **糖苷化** | **56 条** | ❌ 等于没有 |
| **氧化** | 8,641 条（1.2%） | ⚠ 有，但少 |
| **还原** | **54,510 条（7.5%）** | ✅ 意外地多（氢化/NaBH₄ 这类在合成里很常见） |
| 脱水缩合 | 25,213 条（3.5%） | ✅ 有（主要是有机合成的酯化/酰胺化，不是天然产物语境） |

**→ "去 ORD 里挖水解/糖苷化模板"这条路走不通。** 不是挖得不够，是**数据里就没有**：
ORD 是**合成化学**的收录库，合成论文几乎不报水解（水解常是后处理/副反应，不进收率表）。

### 这对你目标的影响
1. **还原/氧化** 可以从 ORD 补（约 54k / 8.6k 条原料）。
2. **水解/糖苷化/美拉德** 必须**另找数据源**：
   - 天然产物降解/代谢文献（如 NP 的 forced degradation 研究）
   - **炮制化学**（中药炮制前后成分变化是现成的"反应前后"对照）
   - 或**专家规则**（化学知识直接写，不从数据挖）——工作区里 63 条手写规则那条路其实正是在做这个
3. 【推断】这也解释了为什么当年那 63 条手写规则里有"糖苷水解"——**那是知识来源，不是数据来源**。

## 四、限制（诚实列清）
1. **60.4% 落到"其它"** → 分类器偏粗（多步/保护基/成盐/金属试剂都归到"其它"）。
   所以上表 水解/氧化 的数字应看作**下界**，但 **0.3% 这个量级不会因为分类细化就变成 30%**。
2. **我第一版写错了一条限制，这里更正**：原以为"水在溶剂列 -> 检测不到水解"。
   实际上**能检测到**——水若不在反应物列，产物的 Δ 依然显示 +H₂O，主判据会命中。
   真实的漏判是**成盐式水解**（NaOH 水解酯 → 羧酸钠盐，ΔH 变 +1 而非 +2），已加**宽松口径**覆盖：
   333 = 0.4%（vs 主判据 206 = 0.3%）→ **量级不变**。
3. 抽样 vs 全量一致性很好（外推 1,907 vs 实际 1,877；54,400 vs 54,510），说明抽样口径可信。
4. 元素收支法**无法区分**"两个底物偶联"与"底物 + 试剂"的差异，只对**净收支**负责；
   凡净收支不规则的记录（金属试剂、保护基迁移、多步串联）都会落到"其它"。
