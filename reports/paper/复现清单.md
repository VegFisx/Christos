## 10. 干净目录复现演练（B10，2026-10-16 实测）

### 10.1 三个环境变量（默认行为不变）

| 变量 | 作用 | 默认 |
|---|---|---|
| `CHEMCREACT_ROOT` | 仓库根（脚本据此找输入、写输出） | `D:\ProgramData\DSHNS\chemreact-staging` |
| `CHEMCREACT_BENCH_OUT` | 基准结果输出目录 | `<root>\reports\paper\results` |
| `CHEMCREACT_LIB` | 基准库文件 | `<root>\reports\paper\data\lib_uspto50k_excl.jsonl` |

### 10.2 干净目录怎么搭（实测）

```
chemreact-staging\repro-20261016\
  core\ rules\ conditions\ sources\ tools\ api\   ← 源码**复制**（约 4 MB）
  libs\                                          ← junction（490 MB，第三方库可重装）
  reports\paper\data\                            ← 输入复制：uspto_processed.csv / uspto50k_canon.jsonl / lib_uspto50k_excl.jsonl
  reports\paper\results\                         ← **空目录**（产物只落这里）
  reports\_shard_*.jsonl                         ← 原始分片 11 个（31 MB）
  reports\retro_template_blacklist.json          ← 覆盖率/可用性脚本要读
```

```powershell
$root = "D:\ProgramData\DSHNS\chemreact-staging\repro-20261016"
$env:CHEMCREACT_ROOT = $root
$env:CHEMCREACT_BENCH_OUT = "$root\reports\paper\results"
cd $root
python -u tools\paper_50k_prep.py                     # 第 0 步
python -u tools\retro_cluster_eval.py --min-freq 3 --per-bucket 3 --skip-eval `
    --out-clustered "$root\reports\paper\data\lib_repro_check.jsonl"
python -u tools\retro_cluster_eval.py --min-freq 3 --per-bucket 3 --skip-eval `
    --exclude-products "$root\reports\paper\data\uspto50k_canon.jsonl" `
    --out-clustered "$root\reports\paper\data\lib_uspto50k_excl.jsonl"
python -u tools\paper_bench_50k_coverage.py 6         # 第 2 步
python -u tools\paper_bench_50k_usability.py 4        # 第 3 步
python -u tools\paper_bench_50k_forward.py 100000 6   # 第 3b 步
```

### 10.3 实测结果与两个必须知道的点

| 步骤 | 结果 |
|---|---|
| 0 目标集标准化 | 50,016 条；产物 **sha256 与发布版逐字节一致**（`FEAC52ECE7F75099…`）｜37 s |
| 1a 不剔除重聚类 | **3,228** 条（与既有库相符）｜2 s |
| 1b 剔除 50k 后 | **3,065** 条（= 发布基准库条数）｜12 s |

1. **内存护栏**：覆盖率/可用性脚本会按**可用内存**自动限制并发，并**打印**降级信息，例如
   `[guard] 可用内存 3.6 GB -> 并发 6 自动降为 1`。内存紧张时**不要**强行加 worker，让它单进程慢跑。
2. **图（第 5 步）需要 matplotlib**：本机在 `D:\TCMAI\venv`（3.12）里；用其它解释器时会跳过出图并打警告。
