## Captions

**Figure 1.** Overview of the Christos system. Inputs are resolved before any
chemistry is run; source adapters remain read-only; the reaction engine writes
candidates to a provenance ledger, which is rendered as CSV/TSV and a
single-file HTML report.

**Figure 2.** Resolution paths for the four supported input families. Tokens
that cannot be matched are reported verbatim rather than forced into a herb,
species or formula record.

**Figure 3.** Example of one forward candidate. The input species, source
compound, rule, condition-evidence marker and candidate product form a
single traceable path.

**Figure 4.** Example of a one-step retrosynthetic route. Both precursors
match the current termination set and the forward validation passes; this is
an annotation, not a laboratory instruction.

**Figure 5.** Summary of frozen benchmark measurements used in the system
paper. The values are not clinical or synthetic-performance claims; see the
result table and protocol for the exact definitions.
