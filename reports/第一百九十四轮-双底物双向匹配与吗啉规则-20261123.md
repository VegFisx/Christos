# 第一百九十四轮：curated 双底物双向匹配 + 吗啉规则

> 用户 2026-11-23：「都做了吧。」本轮同时做：
> 1. curated 双底物模板按两种底物顺序匹配（框架层）；
> 2. 用它接上吗啉双烷基化规则（命名杂环，新增规则）。
>
> 既有规则未改。

## 1 双底物双向匹配

原引擎对每个底物对只调用一次 `apply_pair(sa, sb)`；模板的反应物顺序固定，
因此同一反应在输入顺序相反时会漏掉。吗啉案例实测：

- `BrCCOCCBr + 芳胺`（输入顺序）→ 0 产物；
- `芳胺 + BrCCOCCBr`（反向）→ 正确吗啉产物。

本轮在 `core/smartreact_engine.py` 的 **curated 双底物**分支中改为：

```text
try (sa, sb); if 0 products and sa != sb:
    try (sb, sa)
```

- **规则级开关**：只有规则显式声明 `bidirectional: true`，才在前向 0 产物时尝试反向；
  既有规则没有该字段，行为逐位不变；
- 仅对 curated 双底物规则生效；mined_extra / mined_top / 单底物 / 三底物路径不变；
- 反向命中仍用原始 `sa/sb` 记来源，保持 `source` 与 `partner_smiles` 稳定；
- 反向命中计入 `curated双底物_反向命中`，便于审计；
- 相同 SMILES 的对子不重复跑反向。

### 为什么不做“两个方向并集”

先试过两个方向都跑、并集输出。煎煮 guard 从 **824 增到 925（+101）**；
只保留“前向 0 才反向”的兜底时仍是 **876（+52）**，因为其他既有规则也会
在反向产生新产物。这些不是本轮要解决的顺序依赖，而是额外的区域异构体候选。
最终改为**规则级 `bidirectional: true` 开关**：只有吗啉规则打开；
其余既有规则不加字段，行为逐位不变，guard 回到 **824**。
需要全并集时应作为显式开关另行评估。

## 2 吗啉规则

新增 `cyclization_morpholine_double_alkylation_001`：

```text
芳胺 + 2,2'-二溴二乙醚  ->  N-芳基吗啉 + 2 HBr
```

- `condition_profile: thermal`，`byproducts: HBr 2`，`provenance: cited`；
- 模板按“芳胺在前”书写；双向匹配使其对输入顺序不敏感；
- 文献：*Synthesis with β,β'-Dichloroethyl Ether. Morpholine Derivatives*,
  J. Am. Chem. Soc. 1934, DOI 10.1021/ja01317a065。
  本规则用二溴乙醚同系物（离去基团 Br），反应中心相同；未用 295 案例拟合。
- 未声称具体碱/溶剂；条件层只按 `thermal` 标注。

## 7 边界

- 只对声明 `bidirectional: true` 的 curated 双底物规则做反向兜底；
  mined/extra 模板与其他既有规则仍按原顺序。
- 默认不做双向并集：全并集会让煎煮 guard 824→925，前向兜底版也会到 876；
  两者都属于额外的区域异构体候选，需要单独评估。当前只有显式
  `bidirectional: true` 的吗啉规则走反向兜底，guard 保持 824。
- 吗啉规则目前只认 Br；Cl 同系物需要另立规则或改成能按卤素配平的机制，不混写。
- 反应条件只按 `thermal` 标注，未建模碱、溶剂与具体温度。
