# 待办 4 · 方剂独立入口（用户 2026-10-17 拍板方向）

> 用户原话：「我想把方剂和药材/基元植物区分开（药材和植物可以放一起），单独开辟一块执行方剂的，
> 就设在图里给出的两块之间。」

## 结论（我的回答）：位置对，但要加两条约束

```
预测产物（底物 → 产物）   方剂（复方）   找路线（目标分子 → 路线）
      正向·单味/物种    →   正向·多味复方   →   逆向
```

左到右 = 单味 → 复方 → 逆向，读起来顺；方剂本来就是喂给同一个正向引擎，放中间是"正向的进阶用法"。

## 必须一起改的两件事

1. **版本选择前台化**：现在版本藏在方名下面（默认药典版，其它版本一行字）。
   方剂页应把版本做成卡片：药典（Tier 0）/ ETCM / CPMCP / 古籍 / **AI现查**（带档位与抽检结论）；
   **切版本 = 换组成**，这是方剂页最有价值的交互。
2. **预测页遇方名要指路**：现在预测页也会展开方名 → 会形成两套并行逻辑。
   改成：识别到方名 → 提示「这是方剂，去方剂页」+ 一键跳转。

## 方剂页专属

* **份数可编辑**：药典剂量 → 份数默认算好，用户可手改；
* **剂量加权默认关**（与命令行一致）；
* 页面显式显示：组成 / 剂量 / 份数 / 出处档 / 抽检结论。

## 布局演进（与待办 3 衔接）

* 短期（当前页面）：三块并排，方剂放中间；
* P1 应用布局时：三类任务挪进**左侧栏**（`新任务 → 单味/物种 · 方剂 · 找路线`），顶部只留状态。
