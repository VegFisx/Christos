## 3. ★ bug 八：脱水认不出乙醇 ★

```
SMARTS: [CH2:1][CH1:2][OH:3]>>[C:1]=[C:2].[OH2]
         ^^^^^ 邻碳恰好 2 个氢
                ^^^^^ 羟基碳恰好 1 个氢
```

**探针矩阵里的命中结果：**

| 底物 | 旧写法 |
|---|---|
| **乙醇（CH₃CH₂OH）** | **✗ 匹配不上** |
| 1-丙醇 | ✗ |
| 2-丙醇 | ✗ |
| 2-丁醇 | ✓ |
| 环己醇 | ✓ |

**乙醇脱水成乙烯是脱水反应最基础的例子，这条规则居然做不到**——因为它要求"羟基碳恰好 1 个氢 + 邻碳恰好 2 个氢"，只有 2-丁醇那种形状才满足。

**修法**：`[CH2:1][CH1:2]` → `[CX4:1][CX4:2]`

| 底物 | 修后 |
|---|---|
| 乙醇 | **`C=C`（乙烯）** ✓ |
| 1-丙醇 | **`C=CC`（丙烯）** ✓ |
| 2-丙醇 | `C=CC` ✓ |
| 2-丁醇 | `C=CCC` ✓ |
| 环丁醇 | `C1=CCCCC1` ✓ |

## 4. ★★ 系统扫描氢数约束：一次找出全部同类 ★★

既然「氢数写死」已经第 4 次，就写脚本把**全库所有写死的氢数**列出来：

```
共 21 条规则含写死的氢数约束
```

逐条人工判断，**大部分是合理的**——因为氢数就是**官能团定义的一部分**：

| 规则 | 约束 | 为什么合理 |
|---|---|---|
| 醛氧化 | `[CH1:1]=[O:2]` | 醛碳就是 1 个氢 |
| 伯醇氧化成醛 | `[CX4H2:1][OH:2]` | 伯醇碳就是 2 个氢 |
| 羟基氧化 | `[CH1:1][OH:2]` | 仲醇碳就是 1 个氢 |
| 脱甲基 | `[O:1][CH3:2]` | O-甲基 |
| 糖苷化 / 缩醛水解 / 半缩醛水解 | `[CX4H1:1]` | 端基碳 / 缩醛碳 |

**但有一组不合理：胺类。**

### bug 九（3 条）：只认伯胺，仲胺全灭

| 规则 | 约束 | 化学事实 |
|---|---|---|
| Michael加成(胺) | `[NX3H2][#6]` | 伯胺**和仲胺**都能做 |
| 酯的氨解 | `[NX3H2][#6]` | 伯胺**和仲胺**都能做 |
| 酰胺化(分子间) | `[NX3H2][#6]` | 伯胺**和仲胺**都能做 |

**而仲胺在中药成分（生物碱）里非常常见。**

**修法**：`[NX3H2:5]` → `[NX3;H1,H2:5]`

| | 修前 | 修后 |
|---|---|---|
| Michael胺 + 二甲胺 | ✗ | **`CN(C)CCC=O`** ✓ |
| 酯的氨解 + 二甲胺 | ✗ | **`CC(=O)N(C)C`** ✓ |
| 酰胺化 + 二甲胺 | ✗ | **`CC(=O)N(C)C`** ✓ |

**「氢数写死」这一模式，累计 5 处，本轮全部扫清。**
