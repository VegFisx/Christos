## 2 同义词接入（用用户自己的资源，只读）

`D:\TCMAI\data` 里已有两份资源：

- `ChineseDrugEthnonymsSynonymyTable.xlsx`：50,606 行，8,240 正名 /
  32,571 异名，带《全国中草药汇编》《中华本草》出处 —— **有出处，主用**；
- `herb_aliases_map.json`：31,460 条 别名 -> 正名 —— 自动建的，**有争议条目**。

`tools/audit_formula_db_coverage3.py` 的解析层级：

1. tcm.db 正名（直接命中，永远可信）；
2. tcm.db 别名（同一个别名若指向多个正名 -> **ambiguous，不猜**）；
3. 解析归一化（剂量/炮制/形态）；
4. 同义词表（有出处）；
5. 可选：alias_map（自动表）。

**关键口径**：一个异名如果同时指向两个不同的 tcm.db 药材，记为
`ambiguous`，**不算解析成功**。实测盲选会出错（麦门冬 -> 虋冬、
芙蓉叶 -> 木棉、紫荆皮 -> 南五味子），所以不猜。

| 口径 | 成分提及 | 方剂全解析 |
|---|---:|---:|
| 严格（只认字面名称） | 81.6% | 35.8% |
| 仅解析归一化（v2，未处理别名歧义） | 85.13% | 42.93% |
| **v3 推荐**（有出处同义词表 + 缩写/部位 + 两条补丁） | **85.64%** | **44.29%** |
| v3 全部（再加自动 alias_map） | 86.50% | 46.14% |

v2 与 v3 不可直接比：v2 把「一个别名指向多个药材」也算成功，
v3 把这类改成 `ambiguous` 不计入。**v3 的数字更严、更可信。**
