# 第一百三十四轮：条件到底带不带信息（可行性探针）

日期 2026-11-10 · 脚本 `tools/probe_condition_signal.py`（探针）与 `tools/probe_condition_yield.py`（判据）

## 0. 一句话

条件确实带信息，但很薄：在高/低收率分类上，它的增量是 **AUC +0.024**（bootstrap 95% CI [+0.009, +0.040]），单独用只有 **0.60**。够证明「不是完全无关」，不够支撑「按条件筛掉不该发生的反应」这件事直接上线。

## 1. 问题与判据（先写死再看数）

问句：把条件（温度、时间、溶剂类别、催化剂/试剂有无）加进来，能不能比只看结构更好地判断一次候选反应是否成立？

判据在跑之前写定：**AUC(结构+条件) − AUC(结构) < 0.02 就杀**，即认定条件对筛选没有可用信号，底物层条件闸门在这个数据上不成立。

标签用 ORD 里已测的收率，不编造：正类 = 收率 ≥ 50%，负类 = 收率 ≤ 10%，中间带丢弃（避免刀刃上的样本）。

## 2. 数据口径

- 源：`reports/ord_condition_dataset/*.parquet`（178 片，925,943 行）
- 覆盖率实测：温度 28.5%、时间 55.8%、两者皆有 18.5%、收率 100%、单产物且 SMILES 可解析 94.9%
- 采样后可用 59,030 行：正 57,089 / 负 1,941（专利数据天然偏高收率，正类占 96.5%）
- **类别不平衡处理**：正类降采样到 3× 负类 → 7,764 行（正 5,823 / 负 1,941），避免模型只学基率
- 切分：按**底物集合哈希**切，同一底物不跨训练/测试（测试 1,958 行、1,754 个底物）

特征两组，刻意让「结构」组里不含任何条件：

- 结构（22 维）：产物重原子数、MW、环数、芳环数、立体中心、氢键供受体、杂原子数、C/H/N/O/S/卤/P 计数、底物集合的重原子/环/杂原子/组分数，以及三个差值（重原子、环、杂原子）
- 条件（15 维）：温度、log10 时间、溶剂类别哑变量（水/DMF/DMSO/二氯甲烷/THF/乙腈/醇/酸/碱）、催化剂有无、试剂有无、溶剂组分数

## 3. 结果

不平衡（59,030 行）：

| 模型 | AUC |
|---|---|
| A 只看结构 | 0.7331 |
| C 只看条件 | 0.6144 |
| B 结构+条件 | 0.7535 |

Δ = **+0.0204**，bootstrap 400 次 95% CI [+0.0078, +0.0332]，≤0 的比例 0.000。

平衡后（7,764 行，正类 74%）：

| 模型 | AUC |
|---|---|
| A 只看结构 | 0.7103 |
| C 只看条件 | 0.6025 |
| B 结构+条件 | 0.7347 |

Δ = **+0.0244**，95% CI [+0.0086, +0.0403]，≤0 的比例 0.003。

两种取样下增量方向一致、CI 都不跨 0，所以「条件无关」这个零假设被拒。

## 4. 能说与不能说

能说：

- 条件携带**真实但小**的额外信息（+0.02~0.024 AUC），不是零。
- 单独用条件就有 0.60 的判别力，说明「条件-反应类型」之间存在稳定的经验关联，可以做成一个不依赖机器学习的**经验先验**（查表），完全可审计。
- 结构本身（0.71~0.73）才是主力，条件不能替代它。

不能说：

- 不能说这套东西能「预测哪些候选会真的发生」。标签是**已报告收率的高低**，样本全是「已发生并被记录的」反应；从未发生的反应不在数据里，正负样本都来自同一分布。
- 不能说 +0.024 值得改生产默认值。收率分类 AUC 0.73 的模型，放到候选筛除上未必等价。
- 不能把收率当转化率用：ORD 的收率有文献/专利自报偏差。

## 5. 被这条否掉的设想

原本设想的「底物层条件闸门」若指望**显著**提升选拔（例如像重排序那样 +24 pp），这条数据不支持：条件的增量只有 0.02 AUC。想做真正的底物层判活，缺的是**阴性记录**（没发生的反应），ORD 里没有。

## 6. 下一步（建议，未执行）

把条件做成**经验一致性先验**而不是学习模型：对每个规则族，从 ORD 统计温度/时间/溶剂/催化剂的经验分布，给候选打「条件典型性」分；在 3,000 条基准上测「降权 atypical 候选」是否提升 top-1 且召回不掉。这条路可审计（分布直接来自数据）、可回退（默认关），且不依赖刚才那个 0.73 的模型。
