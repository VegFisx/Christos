# ② 逆模板质量 —— 阶段性报告（2026-10-11）

> 结论先写：**找到了病根并修掉了一批"假路线"，但"造不出真路线"这件事没解决。**
> 所有数字标注「实测」；能复算的都在 `reports/` 里有对应文件。

## 一、病根是什么（实测，不是猜的）

用户点名的是「反转偶联模板给出 `BC(C)=O` 这种怪前体」。查下来是**三种不同的病**：

| 病 | 实测规模 | 例子 | 判定 |
|---|---|---|---|
| **A. 惰性小分子前体**（最要命） | 5 个中药成分的 764 条"全部前体可得"路线里，**42.7% 的前体只有 2 个重原子** | `5-methoxymarmesin` ← 去甲基黄酮 **+ CCl** | **假路线**：另一个前体把整个骨架原样留着，等于"用甲基化造甲基醚"，对合成毫无价值 |
| **B. 含试剂元素的前体** | 300 条模板（suzuki 132 / chan_lam 112 / negishi_batch 44 / ART 12） | `CCNC(C)=O` ← `CC[NH-]` **+ BC(C)=O** | **假可得**：`BC(C)=O` 靠【骨架匹配】命中阿司匹林被误判"买得到" |
| **C. 反转模板本身丢小分子** | 14,926 个切断方案 **100% 与目标不配平** | 酯化/酰胺偶联脱 `H2O`，卤代脱 `HBr` | **不是缺陷**（见下） |

### ★ 一个我自己先搞错、后来被数据推翻的判断 ★

我先写了个"配平诊断"，看到 **14,926/14,926 = 100% 不配平**，一度以为是致命的原理性缺陷。
把差值分布打出来才看清：`H+2+O+1`(1710) / `Br+1+H+1`(1170) / `Cl+1+H+1`(666) …
**全是脱小分子**——缩合反应本来就脱水，模板只含带映射的原子，所以反转后"前体侧多出 H2O"。
**这是缩合反应的正常现象，不是缺陷。** 差值的正确读法是"这个反应脱掉什么"。
→ 记这一笔是为了提醒：**配平检查不能直接当质量判据**，必须看差值分布。

## 二、改了什么（两条护栏，都可开关、都可回退）

### S3：不许"乱匹配"就当成买得到（`retro_search.py: is_available`）

| 规则 | 依据 |
|---|---|
| 含 B/Si/Sn/Zn/Mg/Li/Al/Ti 的分子，**永不**靠骨架匹配算可得 | 实测：`BC(C)=O` 骨架=阿司匹林、`BCC` 骨架=对甲酚，都被误判"可得" |
| 骨架匹配必须**电荷一致** | 负离子不是能买的原料 |
| 骨架匹配重原子数容差 **±1**（可设 0） | 碘代胸苷 vs 胸苷差 1 个碘；碘代物不该被当成胸苷 |

正反例核对（`tools/check_availability_guards.py`，**8/8 符合期望**）：
`BC(C)=O` ✗ / `BCC` ✗ / 水杨酸 ✓ / 乙酸 ✓ / 邻氯苯甲酸 ✓ / 苯 ✓ / `CC([NH-])=O` ✗

### S5：大目标不许拿"2 重原子的惰性小分子"当前体（`retro_search.py: disconnections`）

判据：目标 > 15 重原子，且路线里有一个 ≤2 重原子的前体 → **丢掉这条路线**（小目标不限制）。

**实测效果（`tools/show_before_after.py`）**：

| 目标 | 加护栏前"全部前体可得" | 加护栏后 |
|---|---|---|
| 5-methoxymarmesin | **642 条**（全是 `去甲基黄酮 + CCl`） | **0 条** |
| 胸苷 Thymidine | 0 条 | 0 条 |
| CCNC(C)=O（小目标，对照） | 88 条 | **88 条（未被误杀）** |

| C | B + S3 骨架护栏 | 8/160（5.0%） |

**★ 结论：护栏的代价是 0** —— 从 B 到 E，一步到位数没有掉，
`②护栏杀掉的目标 = []`。也就是说**删掉的都是假路线，没删掉任何真路线**。

中药成分那侧同样（`tools/verify_retro_false_positive.py`，80 个 tcm.db 成分）：

| 档 | 配置 | 有一步路线 |
|---|---|---|

→ **三档完全相同，护栏没有杀掉任何一个目标。**

`5-methoxymarmesin: 642 -> 0` 那条。）

## 四、还没解决的（下一轮要做的）

1. **"能删假路线"≠"能造真路线"**。护栏只能过滤，5.0% 的天花板没被抬高。
   真正抬高天花板要靠**从 ORD 按逆方向重抽模板 + 聚类**（即原方案②的正规做法）。
2. **A 类病的根源在模板本身**：`snar_alcohol / esterification / mitsunobu / williamson /
   ullmann_phenol / ester_schotten_baumann` 这几个类型里，**100% 的路线都带一个 2 原子前体**
   （实测）。说明这些模板反转后只能给出"末端基团替换"，永远给不出骨架切断方案。
   靠 S5 过滤只是不让它们污染输出，**它们本身没有被修复**。
3. **反转模板丢小分子这件事需要有意识地处理**：现在被丢掉的小分子（H2O/HCl/HBr）
   不在前体里，也不在副产物里。正规逆合成会把它们作为副产物标注出来。
4. ①的收尾项仍在：互变异构体归一化、把 265,446 个试剂纳入终端集合。
