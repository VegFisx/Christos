## 二、★ 条件层真的改变了产物，不是改变了打分 ★

### 醇提 vs 煎煮

```
醇提独占 412 个 / 煎煮独占 654 个 / 共有 2437 个
```

醇提多出来的产物，**按规则分布**：

| 规则 | 个数 |
|---|---|
| 脱水 | 58 |
| **酯化(分子间)** | **43** |
| 双键环氧化 | 41 |
| 脱氢成α,β-不饱和羰基 | 37 |
| **酯交换** | **36** |

**实例：**

```
C38H54N2O11  酯化(分子间)   CCOC(=O)CCC(=O)Nc1ccccc1C(=O)OCC12CCC(OC...
C44H66O16    酯化(分子间)   CCOC(=O)C1OC(OC2CCC3(C)C(CCC4(C)C3C(=O)C...
C32H50O4     酯化(分子间)   CCOC(=O)C1(C)CCC2(C)CCC3(C)C(=CC(=O)C4C5...
```

**产物里出现了 `CCOC(=O)`——乙酯。**

> 煎煮条件下水里没有乙醇，这些分子**根本不可能生成**。
> **乙醇不只是改变速率，它本身参与反应。**
> 这就是「醇提 ≠ 水提」在分子层面的证据。

### 无氧煎煮 vs 煎煮

```
无氧煎煮独占 919 / 煎煮独占 2545 / 共有 546
产物数 3091 → 1465（少了 53%）
```

煎煮有、无氧没有的产物，**按规则分布**：

| 规则 | 个数 |
|---|---|
| 脱水 | 367 |
| **羟基氧化** | **323** |
| **双键环氧化** | **254** |
| 脱氢成α,β-不饱和羰基 | 212 |
| 烯烃水合 | 205 |

**氧化类反应整类熄灭** ✓

> 注意 `脱水` 也少了 367 个——**不是脱水被关掉了，而是通往那些脱水产物的路径断在氧化那一步**。
> 级联是路径依赖的：上游没了，下游自然到不了。

### 还原 vs 煎煮

```
还原条件下只有 139 个产物，与煎煮【零重叠】
```

因为还原条件下氧化规则全灭、还原规则激活，**整个产物空间都换了**。

## 三、★ 一个必须正视的问题：产物数量很大 ★

75 个成分 → **煎煮 3091 个产物**。

| 视角 | 评价 |
|---|---|
| 化学上 | 不算离谱——每个成分 42 条激活规则、每个规则最多 3 个产物，逐轮级联 |
| 可用性上 | **3091 条清单没法直接看**，必须靠排序 |

**这就是「产物评分排序」和「多样性排序」存在的理由**：

```
Top-20（多样性排序）→ 覆盖 17 种反应类型，单一规则最多 2 行
完整 3091 条         → 走 --json 输出，按真实分数排
```

**建议**：正式使用时以 **Top-20** 为准，全量清单只用于机器后续处理。

## 六、一句话

**「醇提 ≠ 水提」现在是分子层面的结论**：醇提能产出 `CCOC(=O)` 乙酯，
煎煮条件下水里没有乙醇，这些分子**不可能存在**。

**「无氧煎煮 ≠ 煎煮」也是**：无氧下氧化类整类熄灭，产物少 53%。

**这不是打分差异，是化学差异。**
