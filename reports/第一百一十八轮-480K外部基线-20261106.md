# 第一百一十八轮：USPTO-MIT 480K 外部基线（2026-11-06）

> 一句话：在 479,035 条 USPTO-MIT 上做确定性抽样 39,176 条，我们召回 **71.18%**、top-1 **32.81%**；
> 文献里 Molecular Transformer / Chemformer 在同一语料的 40,000 条 test 上是 top-1 **90.4% / 92.5%**。
> **在宽化学空间里我们不是对手**，这个数字必须写进论文，不能只报 50K 上的 91.71%。

---

## 1. 为什么还要做这一轮

第一百一十七轮已经说明：USPTO-50K 上没有可比的已发表正向 top-1 基线（90%+ 全部报在 480K 的 40,000 条 test 上）。
只报 50K 的 91.71% 会被审稿人问一句「换个数据集呢」。所以补一份同语料的对照。

**拿不到官方切分**：Jin 2017 的 `uspto_train/val/test` 文件只能从其项目里取，
`jsdelivr` 对我们的请求返回 "Package size exceeded the configured limit of 50 MB"（`USPTO/data.zip` 49.7 MB），
`github.com/.../raw/...` 直连被 reset（`curl: (56) Recv failure: Connection was reset`）。
可用的镜像只有 DeepChem 的 `USPTO_MIT.csv`（56,441,634 B，单列 `reactions`，479,035 行，**无切分标签**）。

→ 于是改成**确定性哈希抽样**：`md5(seed + 反应串)` 前 8 位对 10000 取模，取 `< 836`；
seed = `20261106`，比例 8.36%，得 **39,176 条**（≈ 40,000）。同一 seed 任何人都能复现同一批行。

## 2. 口径（写清楚才能比）

| 项 | 我们的做法 |
|---|---|
| 数据 | `reports/paper/data/uspto_mit/USPTO_MIT.csv`，479,035 行 |
| 抽样 | md5 确定性抽样 8.36% → 39,176 条，seed 20261106 |
| 方向 | 只用正向（`reactants>reagents>products` 左→右） |
| 试剂 | **不使用**（我们的引擎只吃底物；文献模型把试剂编码进输入） |
| 底物数 | 只取 1~2 个反应物的行 |
| 主产物 | 多产物时取重原子最多的一个 |
| 条件 | 煎煮 100 °C / 60 min / pH 6.5，1 轮 |
| 配置 | 默认档（mono 6000 / extra 20000 / cap 32） |
| 立体 | 默认开（`CHEMCREACT_STEREO_CANON` 未设 = 1） |

**泄漏已排除**：模板库 `example` 列 9,770 条（可解析反应键 9,206）对 479,035 条做严格同反应匹配 →
命中 **0 条（0.000%）**（`tools/check_mit_overlap.py`）。与 50K 上的 0/50,016 一致。

## 4. 和文献怎么摆在一起（三个必须写的限定）

文献数字（都是 480K 的 40,000 条 test、top-1）：

| 系统 | top-1 | DOI |
|---|---|---|
| Molecular Transformer | 90.4% | `10.1021/acscentsci.9b00576` |
| Augmented Transformer | 90.6% | `10.1038/s41467-020-19266-y` |
| Chemformer | 92.5%（增强 92.8%） | `10.1088/2632-2153/ac3ffb` |
| Graph2SMILES | 90.3% | `10.1021/acs.jcim.2c00321` |
| **本系统** | **32.81%** | 本轮 |

限定一：**切分不同**。他们用 Jin 2017 的固定 40,000 条 test，我们用 md5 抽样 39,176 条；两者都是同一语料的无偏抽样，但样本不同，差异应在抽样误差量级内（本系统 4 片极差 0.6 pp）。

限定二：**输入不同**。他们把试剂/催化剂编进输入，我们只用底物 → 我们处于劣势，但这个劣势是系统设计（模板匹配只看底物）而不是口径作弊。

限定三：**指标不同**。我们报的是「候选集合里有没有」（平均 20 个候选），文献报的是「第一名对不对」。这两个数**不能互相替换**，论文里必须分开列。我们自己的 top-1 是 32.81%（480K）/ 43.28%（50K）。

## 5. 结论（对论文与对外说法）

1. **在策展过的 50K 单步空间里，我们的候选召回（91.71%）是有竞争力的**；top-1（43.28%）不是。
2. **在 480K 宽空间里，我们的召回（71.18%）明显低于文献模型的 top-1（90%+）** —— 这不是指标口径问题，是覆盖问题：9,770 条模板覆盖不了宽空间。
3. 因此对外只能这样表述：**本系统是「知识驱动的候选生成器」，在常见单步反应上召回高、可追溯；不是 supervised 模型的替代品**。任何「我们的 92% 比 MT 的 90.4% 好」的写法都是错的。
4. 可写进 Limitation 的具体句：*On the broader USPTO-MIT corpus (479k reactions), our template-matching engine reaches 71.2% candidate recall and 32.8% top-1, well below sequence-to-sequence models trained on the same corpus (90.4–92.5% top-1); the system is intended as a knowledge-driven candidate generator, not as a replacement for trained forward models.*

