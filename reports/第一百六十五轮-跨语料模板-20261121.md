# 第一百六十五轮：item 3 跨语料模板（USPTO-MIT 外部）

> 问题：模板覆盖的提升是不是只在本语料上好看？换一个**完全不相交**的语料挖模板，
> 还能不能在官方 test 上召回？
>
> 答案：**能。** MIT 外部模板单独 94.79%（shard 0，零泄漏）；
> 并入现有池只 +0.30 pp，但候选 43.5→64.3、耗时 4.8×——不采纳为默认。

## 1 数据障碍与绕法

`USPTO_MIT.csv`（479,035 行）**没有原子映射**（前 2 万行 0 条带 `[C:1]`），
RDChiral 不能直接抽模板。本机 `libs/rxnmapper` 带本地 ALBERT 权重，
离线可用：**31 ms/条**。于是：

1. MIT 按 `md5(seed+reaction)` 抽 2.1%（10,024 条）；
2. **排除整个 USPTO-50k 的 signature**（49,686 个；不是只排除 test）→ 外部样本 9,598 条；
3. 去掉 reagents（只留 reactants>>products），RXNMapper 映射（成功 9,534，失败 64）；
4. RDChiral 抽 retro、翻 forward → **5,275 个唯一模板**（support≥2 1,046）。
   抽取失败 6；耗时 470 s。

协议写死：模板源与 50k **完全不相交**；官方 test 的 4,993 条全部在排除集里。

## 2 结果（官方 test；均开立体枚举）

| 配置（shard 0，999 条） | 召回 | top-1 | top-5 | 候选/反应 | 耗时 |
|---|---|---|---|---|---|
| 默认（shard 0 基线） | 92.39% | 73.87% | 89.69% | 32.8 | 99 s |
| train 覆盖 + 立体（第 164 轮） | 96.70% | 73.17% | 90.99% | 43.5 | 251 s |
| **MIT 外部模板单独** | **94.79%** | 72.27% | 88.99% | 61.1 | 226 s |
| **train ∪ MIT 外部** | **97.00%** | 71.87% | 89.49% | 64.3 | 1,196 s |

- MIT 外部模板单独就有 94.79%：换一个不相交语料，模板法仍然能覆盖大部分官方 test。
- 并入现有池：**+3 条命中**（97.00% vs 96.70%），但候选 +20.8、top-1 −1.30、
  耗时 **4.8×**。
- 这 3 条新命中的模板**全是 support=1**；没有「只加 support≥2」的精简方案。

### 2.1 全量 MIT-only（5 片，4,993 条）

| 指标 | 数值 |
|---|---|
| 召回 | **94.21%（4,704/4,993）** |
| top-1 / top-5 / MRR | 71.52% / 89.10% / 0.7927 |
| 候选/反应 | 63.06 |
| 分片召回 | 94.79 / 94.69 / 94.69 / 93.29 / 93.59 |

对比：train 覆盖 + 立体的全量是 **96.25% / 44.25 候选 / top-1 73.18**。
跨语料模板单独能到 94.21%，但更贵、更弱；它不是生产默认的替代品。

## 3 泄漏审计（关键）

MIT 是 USPTO 的母语料，可能存在近似重复。重建外部样本（9,463 个唯一 signature）
后检查：

| 命中集合 | n | 同主产物 | 同底物集合 | 完全相同（去立体） |
|---|---|---|---|---|
| MIT-only shard0 | 947 | **0** | **0** | **0** |
| merged 新增 | 3 | **0** | **0** | **0** |

也就是说：94.79% 和 +3 条都不是「MIT 里本来就有这条反应」，
而是在局部反应中心层面的**真泛化**。

## 4 结论

1. **跨语料泛化成立**：完全不相交的 MIT 外部模板，单库在官方 test 全量上 **94.21%**
   （shard 0 94.79%）。这是「模板法不是只记住 50k」的直接证据，可作为论文的 robustness 结果。
2. **并入不划算**：+0.30 pp 换 +20.8 候选、−1.3 top-1、4.8× 耗时。
   生产默认保持 **train 覆盖 + 立体枚举**（96.25% / 44.25 / 73.18）。
3. MIT 外部模板的价值是**验证**，不是**生产增量**；除非以后只对
   「train 池完全没有命中」的样本按需加载（需要另做触发信号）。
4. 3 条新命中全来自 support=1，说明外部语料的低支持度模板仍有个体价值，
   但无法与高支持度子集分开取用。
