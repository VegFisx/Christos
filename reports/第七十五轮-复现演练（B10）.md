# 第七十五轮 · B10 复现演练（干净目录）

> 任务：`reports\v1.0.0-验收清单（二区投稿就绪）.md` 的 **B10** ——
> 在**干净目录**按 `reports\paper\复现清单.md` 端到端跑一遍，逐项记录耗时、产物与偏差。
> 本演练**不动用户数据库**（全程只读），所有输出落在 `repro-20261016\`。

## 一、干净目录怎么搭的

```
chemreact-staging\repro-20261016\
  core\ rules\ conditions\ sources\ tools\ api\   ← 源码**复制**（4 MB）
  libs\                                          ← junction（490 MB，第三方库可重装）
  reports\paper\data\                            ← 输入数据复制（uspto_processed.csv / uspto50k_canon.jsonl / lib_uspto50k_excl.jsonl）
  reports\paper\results\                         ← **空目录**：所有产物写这里
  reports\_shard_*.jsonl                         ← 原始分片 11 个（31 MB）
  reports\retro_template_blacklist.json          ← 基准脚本读的黑名单
```

为了让"干净目录"真的成立，本轮把基准脚本的路径改成**可被环境变量覆盖**（默认行为不变）：

* `CHEMCREACT_ROOT` → 仓库根（默认 `D:\ProgramData\DSHNS\chemreact-staging`）
* `CHEMCREACT_BENCH_OUT` → 基准输出目录（默认 `reports\paper\results`）
* `CHEMCREACT_LIB` → 基准库文件（默认 `reports\paper\data\lib_uspto50k_excl.jsonl`）

涉及脚本：`paper_50k_prep.py`、`retro_cluster_eval.py`、`paper_bench_50k_coverage.py`、
`paper_bench_50k_usability.py`、`paper_bench_50k_forward.py`、
`paper_instability_experiment.py`、`paper_make_figures.py`。

## 三、偏差与说明（如实记）

1. **内存护栏生效**：第 2 步启动时打印
   `[guard] 可用内存 3.6 GB -> 并发 6 自动降为 1（每 worker 预留 ~0.8 GB）`。
   本机当前可用内存偏低（用户环境里还跑着别的东西），全量 50k 的覆盖率评估会明显变慢 ——
   这是**脚本设计内的保护**，不是错误。
2. **图（第 5 步）已重跑（2026-10-17）**：用 `D:\TCMAI\venv\Scripts\python.exe`
   执行 `tools\paper_make_figures.py`，设置 `CHEMCREACT_ROOT=D:\ProgramData\DSHNS\chemreact-staging`，
   写出 fig1–fig6；fig3 已切换为 B10 的 50,016 目标 / 3,065 模板口径（79.81%），
   旧 94.7% 图已备份到 `reports\paper\figures.before-b10-rerun\`。
   `tools\_fig7.py` 是硬编码数据的一次性脚本，本次未重跑，原 fig7 保留。
   ★ 口径：主线 94.7% 是 `n_targets=5,002` + `lib_templates=79,184`（v2 库），
   B10 79.81% 是 `n_targets=50,016` + `lib_templates=3,065`（泄漏剔除库）。
   A4 已决定 **USPTO-50k 全量图采用 B10 79.81%**；94.7% 只能在图注里
   明确写“5,002 目标 + v2 库”时才可使用。
   逐项核查见 `reports\第七十五轮-B10-fig3口径核查.md`。
3. 第 0 步的**逐字节一致**是最强的一条复现证据（同一输入 → 同一输出字节）。
4. ★★ **演练抓到一处真缺口（已修）**：复现清单第 3b 步只写了
   `paper_bench_50k_forward.py 100000 6`，**没写环境变量**——第一次照此在干净目录里跑，
   得到的是**默认小库**的 **41.28%**（候选均值 0.7、空集 52.35%），与论文的 82.32% 差了一倍。
   原因是：论文口径需要 `CHEMCREACT_BENCH_EXTRA_TPL/MONO_TPL` 指向**泄漏剔除版全量库**
   （`mined_forward_templates_full_lf.jsonl`，80 MB）并带上 extra≥10/20k、mono 6k、
   `max_products_per_pair=32`、prefilter 开、以及 `TAG=lf_cap32_20k_full50k`。
   补齐后重跑得 **82.54%** ✓。**清单已按此补正**（见 `复现清单.md` §3b）。
   —— 这正是"干净目录演练"的价值：漏一个环境变量，数字就完全不是论文里那个。

## 四、复现命令（干净目录版）

```powershell

$env:CHEMCREACT_ROOT = $root
$env:CHEMCREACT_BENCH_OUT = "$root\reports\paper\results"
```
