## 二、主力来源：HTE 实验失败条件（已落地）

- **来源**：[Zenodo 19635488](https://zenodo.org/records/19635488)（`schwallergroup/bh-hte-ood`，Apache-2.0，1.84 MB）
- **内容**：`BH_HTE_Curated_Dataset_v20260219.csv`，**27,497 行 × 44 列**（8 个来源），
  字段含 Aryl/Amine SMILES、Catalyst/Base/Solvent（名字+SMILES）、**Yield**、Product SMILES、二分 `labels`。
- **负例口径**：`Yield == 0` = HTE 实测没检出产物 → **实验失败**（不是推断、不是合成）。
- **规模（实测）**：**10,696 条条件级反例**；**1,993 个底物对全 0**（其中 58 对测了 ≥5 个条件）；
  **459 个底物对**同底物不同条件既有 0 也有 >0（做条件门控评估的黄金子集）。
- **已用它测出的数字**：假阳性 **94.9%**（强反例 58 对：**93.1%**）、召回 **64.0%**、条件门控 **AUC 0.530**。
- **产物**：`reports/hte_negatives.jsonl`、`reports/hte_negatives_summary.json`，脚本 `tools/hte_negatives.py`。

## 三、第二种口径：合成**选择性**负例（RegioSQM20，已下载）

- **来源**：[SI_RegioSQM20](https://github.com/jensengroup/SI_RegioSQM20)（`RegioSQM20/compounds.smiles`，21.4 KB，535 行）
- **格式实测**：`name / SMILES / 正确位点索引表`（第三列是 `2` 或 `1,3,5` 这样的索引，**不是卤素数**——
  我第一版脚本按"卤素数"读错了，已按实际字段重算，脚本 `tools/probe_regiosqm_negatives.py`）。
- **负例口径**：正确位点 = 正例；底物上**其它芳香 C–H 位点** = 负例（换位点）。
- **规模（实测）**：正确位点分布 {1 个: 471, 2 个: 60, 3 个: 3, 4 个: 1}；
  **可生成合成负例 ≈ 2,079 条**（平均 3.9 条/底物）。
- **它测的不是同一件事**：这是**选择性**（该发生在哪个位置）而非**活性**（会不会发生）。
  我们的引擎经常一次给多个区域异构体，所以这条口径**正好能查它的选择性假阳性**。

## 四、第三种口径：合成负例的两种配方（方法参考）

来源：[Zenodo 15132405](https://zenodo.org/records/15132405)（论文 *Negative Chemical Data Boosts
Language Models in Reaction Outcome Prediction* 的代码，CC-BY-4.0，191 KB）。实测其代码：

1. `data_generation/negative_reactions_generator.py`：**换位点**造负例
   （把卤素加到非正确芳香位点；并生成"备选目标"作为负例）。
2. README 的 `generate-synthetic-classification-dataset`：**用模型 beam-search 的前 3 个预测**
   与真实目标比对，造出正/负分类数据（预测 ≠ 目标 → 负）。

→ 这两种都是**合成负例**，成本低、量可以很大，但**不能用来估计"实验假阳性率"**
（它们不含"实验做不出来"这个信息）。用它们只能做**内部一致性/选择性**检查。

## 六、结论与建议（我的判断）

1. **"有没有反例"这个问题已经解决**：HTE 给 10,696 条实验失败 + 459 个条件对比对，
   许可干净、体积小、已落地——**测"会不会发生"终于有分母了**。
2. **不同来源的负例不能混用**：
   - HTE（实验失败）→ 测**活性/条件**；
   - RegioSQM20（换位点）→ 测**选择性**；
   - beam-search 合成负例 → 只能做内部一致性。
   混用会把两个指标搅成一个说不清的数（这正是我上一轮把 ORD 的 0% 伪影当成反例的教训）。
3. **专利比较例仍是未解决项**，卡在数据入口（本环境 403/超时），不要写成"已完成"。
4. **优先级**：先用 HTE 把"条件感知判据"做出来（AUC 0.53 → 目标显著 >0.5），
   再考虑 RegioSQM20 的选择性检查；专利路线等有下载入口再说。
