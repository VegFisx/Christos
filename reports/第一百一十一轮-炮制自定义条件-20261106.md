# 第一百一十一轮：炮制条件改为用户自填

**一句话**：炮制档新增「炮制·自定义」——溶剂、温度、时长、pH、催化剂、气氛全部由用户填；
原有 9 个档保留为「参考值」，不再当作定论。

---

## 1. 为什么改

上一轮（第 110 轮）把 9 个炮制档逐条核了文献，结果是 **2 支持 / 2 近似 / 4 查无出处 / 1 错配**：

| 档 | 文献核实 | 问题 |
|---|---|---|
| 蜜炙 120 °C / 13.5 min | supported | 唯一逐位一致 |
| 炒黄 165 °C / 10 min | approximate | 莱菔子 160 °C/3 min、120 °C ≤10 min |
| 蒸制 100 °C / 120 min | approximate | 红参 90–100 °C/2–3 h，且是引言背景陈述 |
| 盐炙 150 °C / 10 min | not_found | 专利为 175–185 °C/5–10 min |
| 酒炙 140 °C / 5 min | not_found | 药典柴胡只有醋柴胡 |
| 醋炙 84 °C / 35 min | not_found | 84 °C 是延胡索的值，且查不到原始出处 |
| 炒炭 260 °C / 35 min | not_found | 实测文献 290–390 °C / 3–6 min |
| 炒焦 195 °C / 10 min | **mismatch** | 该值是「酒炙黄芩」，焦麦芽是 217–286 °C |
| 姜炙 150 °C / 40 min | not_found | 药典用生姜 12.5%，非 10% |

硬改这些数字会把整套炮制基线推翻，而且仍然只是「换一份文献值」。
用户决定（2026-11-06）：**默认让用户自己填条件**，把「猜」从代码里挪到用户手里。

---

## 2. 改了什么

### 2.1 新条件档 `炮制·自定义`（`conditions/templates.py`）

```python
"炮制·自定义": Conditions(
    solvent="none", temperature=150, time_min=30, pH=7.0,
    catalyst=None, atmosphere="air",
),
```

- **占位基线**：引擎需要一组完整的 `Conditions` 才能算条件门控与 extent，
  所以给了「干热、无溶剂、150 °C、30 min、常压空气」。它不是任何文献工艺。
- **走炮制严格模式**：`chemreact.py` 判据是 `a.cond.startswith("炮制·")`，
  所以它和炒黄/蜜炙一样只跑 `rules/paozhi_evidence.json` 的 11 条证据规则，
  不加载 ORD 自抽模板。
- **不自动加载辅料**：`炮制·自定义` 没有对应的辅料映射，默认不加共底物；
  要加辅料仍需选具体工艺档，或后续给自定义档加辅料选择（见 §5）。

### 2.2 出处登记（`conditions/template_provenance.json`）

新增词表项与条目：

```json
"status_vocabulary": {"user_input": "用户自定条件（2026-11-06 起炮制默认让用户自填），不是文献预设值"},
"炮制·自定义": {"status": "user_input", "match": "n/a",
               "template_values": {"solvent":"none","temperature":150,"time_min":30,"pH":7.0,"atmosphere":"air"},
               "source": {"title":"用户指令","type":"user_requirement"}}
```

`templates.list_templates()` 会把它标成 `[用户自定]`；`provenance_of()` 返回 `status=user_input`。

### 2.3 界面（`integration/tcmai_bridge/ui_page.html`）

- 三处条件下拉（主表单 `#cond`、方剂表单 `#f_cond`、设置 `#set_cond`）新增
  `炮制·自定义（自己填）`。
- `PRESETS` / `MAP` 补一行，选中后自动把占位基线填进下面六个输入框：
  `['none',150,'30','7','none','air']`。
- `COND_EN` 补英文名 `Processing: custom conditions`。

### 2.4 命令行

`--solvent / --temperature / --time-min / --ph / --catalyst / --atmosphere`
本来就有（映射到 `cond_override`），本轮只补了 `--cond` 的帮助文本与两条提示：

```
[条件] 炮制·自定义：用户指定 solvent、temperature、time_min、ph；其余沿用占位基线
[条件] 炮制·自定义：未填写任何条件，全部沿用占位基线 无溶剂 / 150°C / 30 min / pH 7 / 空气
        —— 这组值不是文献工艺，请自行填参
```

**为什么必须提示**：否则用户会以为「150 °C / 30 min」是某个文献工艺，这正是第 110 轮查出来的毛病。

## 3. 实测

| 命令 | 结果 |
|---|---|
| `predict --herb 甘草 --limit 6 --rounds 1 --cond "炮制·自定义"` | 43 产物 / 0.5 s，打印「未填写…占位基线」提示 |
| 同上 + `--temperature 180 --time-min 20 --solvent none` | 43 产物，`condition_details` 记录 180 °C / 20 min / none |
| 同上 + `--temperature 200 --time-min 15 --solvent water --ph 5` | 43 产物，条件记录 water / 200 °C / 15 min / pH 5；条件层给出「温度 200 °C 高于惯用上限、按高温加速处理」 |
| `--cond 炮制·自定义` 未填参数 → EXIT 0 | 提示正确，产物数与严格模式基线一致（43） |
| `templates.get_template("炮制·自定义")` | `none / 150°C / 30min / pH 7 / air` |
| `tools/test_template_provenance.py` | **ALL PASS（6 组）**，22 个模板全覆盖 |
| `tools/check_ui_js.py` | **2/2 block(s) passed**（752 / 76,404 字符） |
| `tools/audit_mapped_safety.py` | ERROR 0 / WARN 13 / 自检 8 通过 |

产物数 43 与「炮制严格模式」基线一致（甘草 limit 6、1 轮），说明新档没有引入额外规则。

## 4. 复现

```powershell
$PY='D:/TCMAI/venv/Scripts/python.exe'
Set-Location 'D:/ProgramData/DSHNS/chemreact-staging'

# 1) 全默认（占位基线）
& $PY -I integration/tcmai_bridge/chemreact.py predict --herb 甘草 --limit 6 --rounds 1 `
    --cond "炮制·自定义" --out _diag/custom_paozhi --no-report

# 2) 用户填参
& $PY -I integration/tcmai_bridge/chemreact.py predict --herb 甘草 --limit 6 --rounds 1 `
    --cond "炮制·自定义" --temperature 180 --time-min 20 --solvent none `
    --out _diag/custom_paozhi2 --no-report

# 3) 自检
& $PY -I tools/test_template_provenance.py
& $PY -I tools/audit_mapped_safety.py
```

界面上：打开「单味 / 物种 · 预测产物」→ 条件下拉选 `炮制·自定义（自己填）` →
下面六个框会填入占位值，改完直接跑。

## 5. 还没做

1. **辅料选择**：自定义档目前不带蜂蜜/黄酒/米醋等共底物。要支持得把
   `rules/paozhi_adjuvants.json` 的映射从「按工艺名」改成「用户勾选辅料」，
   涉及 `paozhi_adjuvants.describe()` 与引擎共底物入口，约 1 轮工作量。
2. **自定义档的艺术性预设**：现在选中后填的是占位值，用户得自己知道该填多少。
   后续可给「参考区间」提示（如炒黄 120–170 °C / 3–10 min），但仍标注为参考、不参与门控。
3. **9 个预设档是否保留**：目前保留并标 `[文献]/[二手]/[惯例]` 标签。
   若用户希望界面上只留自定义档，需要再改三处下拉。
