# 第 28 轮进展：把「已知错误的热力学信号」从排序里摘出去

> 本轮**未修改 `D:\TCMAI` 下任何文件**。

---

## 1. 起点：上轮只"记录"了问题

上轮发现：**气相 xTB 给水解反应的 ΔG 是正的**，而化学上应该是负的。
这会**系统性压低糖苷/酯水解产物**——而这两类恰恰是中药煎煮里最常发生的反应。

上轮的处置是：

> 「目前**如实记录，不加人为修正**（加修正就是编数据）」

**这句话对，但不够。** 本轮想清楚了：

> **"不修正数据" ≠ "必须把已知错误的信号喂给排序"。**
> 正确做法是**识别出哪些信号不可信，然后不用它**。

---

## 2. 先把边界量准（8 个案例）

```
案例              片段       ΔG     预期   判定
────────────────────────────────────────────────
酯水解            2→2      13.2     负    ✗错
糖苷水解          2→2      11.0     负    ✗错
酰胺水解          2→2      34.6     负    ✗错
亚胺水解          2→2      13.0     负    ✗错
★环氧化物开环     2→1     -28.5     负     ✓
内酰胺开环        2→1      88.3     负    ✗错
水合·烯烃         2→1     -69.3     负     ✓
水合·烯酮         2→1     -15.4     负     ✓
```

### 结论

| 类别 | 符号 |
|---|---|
| **水【切断】一根键**（酯/糖苷/酰胺/亚胺/内酰胺水解） | **4/4 全错** |
| **水【加成】上去**（烯烃水合、烯酮水合） | 2/2 全对 |
| **张力释放型开环**（环氧化物） | 对 |

**判据是化学键类型**——不是"涉不涉及水"，也不是分子大小。

> 注意 `内酰胺开环` 虽是 2→1（加成式片段数），但它切的是**酰胺键**，
> 和"酰胺水解"是同一类化学 → 同样错。**所以不能用片段数做判据。**

### 一个反例

`环氧化物开环成二醇` 被归在 `hydrolysis` 类，但它其实是**加成开环**（张力驱动）。
实测 ΔG = −28.5，**符号正确** → **不该被牵连**。

---

## 3. 修法：知识写进数据，不写进代码

给规则库里 9 条规则加标记（**唯独不标环氧化物**）：

```json
{
  "id": "hydrolysis_ester_001",
  "name": "酯水解",
  "thermo_unreliable": true,
  "notes": "... 气相 xTB 的 ΔG 对本规则【符号系统性错误】 ..."
}
```

`scorer.assign_thermo` 读到标记就跳过：

```python
for p in products:
    rule = rule_by_id.get(p.rule_id)
    if rule is not None and rule.get("thermo_unreliable"):
        n_skip += 1
        p.dg_kj = None
        p.stability = None
        continue
```

**为什么写在 rules.json 而不是代码里**：这样知识跟着数据走。
将来发现硫酸酯水解其实算得准，改数据就行，不用动代码。

## 5. ★ 顺带发现：两个测试的前提被证伪了 ★

改动之后，两个测试红了：

```
test_thermo_final        ✗ 小分子场景 ΔG 覆盖率 > 70%（实测 0/10）
                         ✗ ΔG 有区分度
test_thermo_integration  ✗ 有产物拿到了 ΔG
                         ✗ 同一规则内 ΔG 有区分度
```

### 为什么红

`test_thermo_final` 的场景 A 标题写的是：

> **「场景 A：小分子（酯类）—— xTB 应当给出可用 ΔG 并真正参与排序」**

**它假设"分子小 ⇒ xTB 就准"。而我这轮刚测出：酯水解恰恰是符号系统性错误的那一类。**

> **真正的判据是反应类型，不是分子大小。** 测试把这个错误假设写死了。

### 怎么修

不是"改数字让它过"，而是**改前提**：

- 场景 A 改用 **烯烃水合**（同为小分子，但 ΔG 可靠）
- **并加一条反面验证**：水解类确实被跳过
- 再加两条：规则确实带标记、环氧化物确实**不**被跳过

```
test_thermo_final        14 通过 / 0 失败  （原 11/2）
test_thermo_integration  13 通过 / 0 失败  （原 10/2）
```

**修完的测试比原来更有价值**——它现在同时守住了"该用的用"和"不该用的不用"。
