### 事实

官方 Download 页面（页面标注 `Version: October 2026`）再次写明：

- 数据在 **Creative Commons CC0** 下发布；
- 允许 free use、modification、distribution；

证据：

- `coconut_about.html`：`https://coconut.naturalproducts.net/about`
- `coconut_download.html`：`https://coconut.naturalproducts.net/download`
- 同目录 SHA-256 清单

### 对本地库的结论

上游数据的许可已经核实为 **CC0**，代码为 **MIT**。但本机
`D:\TCMAI\coconut.db` 是库主侧快照，数据库内没有版本字段；因此不能仅凭本地库证明它对应
官方 October 2026 版本。当前快照实测：

```
size  = 295,358,464 bytes
time  = 2026-09-15 00:21:02
sha256 = 4bc668dd37a9144b8a566494ac99046147072a27e04a0e35a712e43e76de56c7
```

所以结论分两层：**上游数据 CC0 已核实；本地快照的来源/版本由库主/维护者确认后才适合公开再分发。**

## 四、AiZynthFinder 过滤器默认值

2026-10-18 抓取官方 `master` 源码：

- `aizynthfinder/context/policy/filter_strategies.py`
- `aizynthfinder/context/stock/...` 的官方 stocks 文档

代码中实际存在四类过滤器：

| 类 | 作用 |
|---|---|
| `BondFilter` | 冻结键不得在逆反应中断裂 |
| `QuickKerasFilter` | 学习型可行性模型，**代码默认 `filter_cutoff = 0.05`**，`prob >= cutoff` 才放行 |
| `ReactantsCountFilter` | 反应物数量必须符合模板预期 |
| `FrozenSubstructureFilter` | SMARTS 指定的子结构不得被切掉 |

实现方式是拒绝式：不通过时直接 `raise RejectionException`，候选会被移出搜索。
仓库级 YAML 没有统一的默认 filters 配置；可核到的是代码级默认 0.05 和类定义。

证据：`aizynthfinder_filter_strategies.py`、`aizynthfinder_tree.json`、
`aizynthfinder_stocks.rst`。AiZynthFinder 仓库许可证为 **MIT**。
