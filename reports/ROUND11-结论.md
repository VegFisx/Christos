## 2. 三条 verify 的真相：两个是真错，一个从来没坏

### ① 先纠正我自己的一个错误认知

我一直以为 SMARTS 的 `X` 是"重原子连接数"，所以 `[CX3H]` 会匹配到"3 个重原子邻居"的碳。
**实验证明我记错了：**

```
肉桂酸的 α 碳：重原子邻居=2  含H总连接=3  显式H=1

[CX3H]    匹配      ← X 算的是【含氢总连接数】
[CX2H]    不匹配
```

所以原来写 `[CX3H]` 是**对的**。**记忆不可靠，实验才可靠**——这个基础问题不先验证，后面全是瞎猜。

### ② 分子内半缩醛化：SMARTS 链写错了

```
错: [CX3H1:1]=[OX1:2][CX4:3]...     读作 C1=O2，且 O2 再连 C3
对: [CX3H1:1](=[OX1:2])[CX4:3]...   读作 C1(=O2)，O2 是【分支】
```

SMARTS 是**线性链**语法，`=O` 后面接着写原子，意思就变成"氧再连下一个原子"了。
（有意思的是：同一个错误在「分子内酰胺化」里我没犯——那里我写对了括号，所以它反而能匹配上。）

**修完实测：4-羟基丁醛 `O=CCCCO` → `OC1CCCO1`（2-羟基四氢呋喃）** ✓

### ③ 分子内酰胺化：两个问题叠加

```
a) 反应物里漏了羧基的 OH          → 配平账目不清
b) 产物氮写成 [NX3H2]              → 成环后氮有 2 重原子邻居 + 2 H = 4 价，
                                     中性氮只能 3 价，RDKit 报「价态非法」
   应为 [NX3H1]（内酰胺的 NH）
```

**修完实测：4-氨基丁酸 → `O=C1CCCN1`（γ-丁内酰胺）+ 水** ✓

### ④ 肉桂酸型脱羧：**从来没坏**

肉桂酸、咖啡酸、阿魏酸三种底物**全部正确**产出苯乙烯型产物 + CO₂。

校验器报「无底物匹配」，只是因为 **2500 个数据库样本里恰好没有肉桂酸型分子**。

## 3. ★ 这个坑我踩了三次，本轮从机制上堵掉 ★

「样本里没有底物」≠「规则是错的」——**这件事已经误伤我三次**：

| 规则 | 校验器说 | 真相 |
|---|---|---|
| 丙二酸型脱羧 | 无底物匹配 | 手工一测（丙二酸、乙酰乙酸）全对 |
| 肉桂酸型脱羧 | 无底物匹配 | 手工一测（肉桂酸等）全对 |
| 分子内酰胺化 | 无底物匹配 | 手工一测（4-氨基丁酸）全对 |

**根因**：`tcm.db` 里没有这几类分子（β-二羰基酸、肉桂酸型、γ-氨基丁酸型）。
校验器在真实底物上跑，样本里没有就只能报 `NO_SUBSTRATE`——
而这个结论**既不能证实也不能证伪**，很容易被误读成"规则坏了"。

### 解法：新增 `probe_substrates`（人工指定底物）

```json
"probe_substrates": [
  {"smiles": "OC(=O)CC(=O)O", "name": "丙二酸"},
  {"smiles": "CC(=O)CC(=O)O",  "name": "乙酰乙酸"}
]
```

校验器**优先跑数据库底物；覆盖不到时，用手工底物补验**。

还新增了一个 verdict 区分两者的**证据强度**：

| verdict | 含义 |
|---|---|
| `PASS` | 2500 个真实底物上跑通 —— 证据强 |
| `PASS_PROBE` | 只有人工底物跑通 —— 证据来自人工，不是抽样 |

已给 10 条稀有规则加了人工底物，覆盖：丙二酸脱羧、肉桂酸脱羧、分子内酰胺化、
分子内半缩醛化、硫酸酯水解、亚胺水解、胺氧化、β-酮酸脱羧、硝基还原、Michael 加成。
