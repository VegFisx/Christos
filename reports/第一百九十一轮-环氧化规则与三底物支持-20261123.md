# 第一百九十一轮：硫叶立德环氧化规则 + curated 三底物支持

> 用户选择第 1、2 项：扩引擎三反应物支持；给环氧化补碱/叶立德前体建模。
> 既有规则未改。

## 1 第 2 项：硫叶立德环氧化规则

新增 `cyclization_epoxide_sulfur_ylide_001`：

- 反应：二芳基酮 + 三甲基锍盐（碱中生成硫叶立德）→ 环氧乙烷 + 二甲硫醚 + H2O；
- `co_reagents: OH- 1`（只用于配平记账，不声称具体碱）；
- `byproducts: C2H6S 1 / H2O 1`；
- 条件档 `ambient`，provenance `cited`。

依据：山东化工 2024, 53(16):82–84；现代农药 2016(6)；化学学报 2000, 58(4)。
模板由二苯甲酮 + 三甲基锍盐标准例经 RXNMapper+RDChiral 派生；未用外部案例拟合。

专用验证 `tools/validate_epoxide_sulfur_ylide.py`：**4/4 PASS**

- 标准正例：二苯甲酮 + 三甲基锍盐；
- held-out：`US08497294B2`；
- 负例：二苯甲酮 + 二甲硫醚、苯甲醛 + 锍盐；
- 配平：酮 + 锍盐 + OH⁻ = 环氧化物 + 二甲硫醚 + H2O；
- 引擎生成 1 个去重主产物。

## 2 第 1 项：curated 三反应物模板支持

引擎原来只把 n_tpl=1/2 的 curated 规则加入模板表，n_tpl=3 被计为失败或跳过。
本轮增加：

- `SmartReactEngine.curated_triple_templates`；
- `_load_curated_templates` 接受 n_tpl=3；
- `_extra_results` 对 `uniq(substrates)` 取三元组，受 `max_triples` 封顶，
  用 RDKit `RunReactants((ma,mb,mc))` 生成产物，写入 `ReactionResult.reactant_c`；
- 默认没有三底物 curated 规则，因此既有行为不变。

验证 `tools/test_curated_triple.py`：用 **Mannich 标准例**
（二甲胺 + 甲醛 + 丙酮 → 4-二甲氨基-2-丁酮 + H2O）注入一条三底物模板，
引擎枚举出目标产物，**PASS**。

### 2.1 吗啉的说明

吗啉案例实际是 **2 个分子**：苯胺 + `BrCCOCCBr`。RDChiral 抽模板时把
两个溴乙基臂拆成了两个反应物片段，才表现为 3 个 template reactants；
这不是真正的三组分反应。三底物支持已就绪，但吗啉应另写成 2 反应物规则，
不能拿这个 3 片段模板当“三组分”硬套。
