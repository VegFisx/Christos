> 2026-10-15。用户新增基础原则："任何需要筛选/排序的功能都要做一个开关"，并要求先评估。
> 本轮 = 评估 + 把"不需要拍板"的清单做掉（透明化、全部成分档、公平截断、报告结构图）。

## 一、原则评估（结论：成立；配套三条修正，已按此实现）

**"取舍必有开关"成立**，与项目基调（生成 + 标注 + 留证）一致。三条修正：

1. **先分类**：
   - 取舍型（黑名单 / 轮数 / 成分数 / 对子预算 / 门槛）→ **必须有开关**（本原则覆盖的范围）；
   - 显示型（报告筛选 / 分组 / 只看有证据）→ 默认"全显示"，开关只影响浏览、不改数据；
   - 定义型（无效 SMILES / 同分子去重 / 产物==底物剔除）→ **不能给开关**（它们是定义，
     关了只会产出假数据）；写进文档说明即可。
2. **默认值纪律**：取舍开关默认"最不取舍"（关 / 全保留）；**打开时必须留证**——
   开关状态写进 `.meta.json` 并与报告同步显示（本轮落地）。
3. **防爆炸**：开关集中登记；界面用"预设档位"包小开关；新功能默认不引入新开关，
   除非它真的做了取舍。

补一句真话：开关保证"不偷偷取舍"，不保证"取舍得对"；所以三件套 = 开关 + 留证 +
报告里显式写出"截了多少、谁没参与"。

## 二、引擎：公平截断（fair_sample_pairs，新开关，默认关）

* `core/smartreact_engine.py`：对子数超 `max_pairs` 时，`fair_pairs=True` 用**公平截断**
  （按伙伴距离分层、半环内等步长散开；确定性、无随机）。
* **实测对照**（n=342 底物、预算 4000）：
  - 旧（顺序截断）：各成分伙伴数 **11 ~ 341**（第 1 个成分与所有人配对，越靠后越陪跑）；
  - 新（公平截断）：伙伴数 **23 ~ 24**（n=100/预算 1000 时全员恰 19）。
  - 两次调用结果完全一致（确定性 ✓）；对子总数 ≤ 预算 ✓。
* 其余档位回归：预算 ≥ 全量时两种模式同结果（n=48 → 1128 对、伙伴 47 ✓）。
* `stats` 新增 `pairs_fair` 标记；`RunSpec.fair_pairs` 贯通；桥接新增 `--fair-pairs` 开关。
* **迷你端到端**（甘草 6 成分、预算 8）：顺序模式伙伴数 1~5、产物 133；公平模式 2~3、产物 150
  —— 截断方式真实影响覆盖面（结果已按新纪律写进 meta）。

> 勘误（过程留痕）：我先前口头说"顺序截断会把尾部成分完全排除"——**不对**（实测：
> 第 1 行配对就覆盖了全部成分）。正确的是"参与度极不均（11~341）"。已按勘误后的口径实现与记录。

## 三、桥接：透明化 + `--limit all`（这次起，每次运行都留证）

* `chemreact.py predict`：
  - 先全量读出该药材成分（只读），再按开关截取；打印"可用 N 个 → 本批取 M 个"；
  - `--limit all` 不截取；运行前**预估算对子覆盖**（预算 vs 总对子、伙伴数范围、
    顺序/公平模式），截断时打 ⚠ 提示；
  - `.meta.json` 新增三块：`selection`（取谁 / 谁没参与（前 120 名单+总数） / 排序口径）、
    `switches`（limit/rounds/cond/triples/fair_pairs/max_pairs/direction/score/reagents）、
    `pair_coverage`（pairs_total/used/mode/min~max 伙伴数）。
* **实测**：白芥子 `--limit all`：可用 14 → 全取 14、对子 91 < 4000 不截断、报告正常生成。
* **样例勘误（顺带发现，如实记录）**：10-14 的两份示例台账其实只用了 **3 个甘草成分**
  （当时库里甘草只解析出 3 个，不是 12 个）——那个"48 产物"是 3 成分跑出来的。今天用同一命令
  复跑（12 个成分全参与）得 **552 产物 / 6.7 s**；示例报告与三步页小样已全部换成新样例
  （`reports/sample_552_甘草.report.html`、`reports/界面小样-三步页.html`）。
* 排序口径现状（如实标注在记录里）：marker 优先 → 分子量降序 → 结构去重（已知偏差：
  偏大分子；黄芪例：前 12 全是皂苷、小分子黄酮被挤掉）。换口径等你给判据（药典试点方案）。

2. **"只看有条件证据的"开关**（显示层，默认关）：勾选后只显示条件依据为"窗口命中/降权"的

4. 已验证：新 meta 报告（150 产物）含运行记录+截断警告+123 SVG；旧 meta 报告向后兼容
   （48 产物 51 SVG，2.3 MB）。
