# 第一百一十六轮：删掉无出处的 `extent_min`，换成数据导出的痕量阈值

日期：2026-11-06
范围：`conditions/kinetics.json`、`conditions/extent.py`、`core/reaction_paths.py`、`tools/test_condition_extent.py`

## 0. 一句话

`gates.extent_min = 0.10` 是第 84 轮我自己编的「不到十分之一参照转化率就不报」。
它没有文献出处，而且第 113 轮标定显示真实煎煮 1 小时的糖苷水解转化率只有 **0.7 %~6.9 %**——
**0.10 会把整批真实产物删掉**。本轮把它改成 **0.0**（永久 no-op），另立一个
**由已发表数据导出的痕量阈值 0.05**，只用于标注、不用于过滤。

## 1. 为什么 0.10 必须删

| 事实 | 数值 | 出处 |
|---|---|---|
| 真实煎煮 1 h（80 °C）糖苷水解转化率 | 0.7 % | J Pharmacopuncture 2020，`10.3831/KPI.2020.23.012` 拟合 |
| 同上 94 °C | 4.4 % | 同上 |
| 同上 105 °C | 6.9 % | 同上 |
| 旧阈值 `extent_min` | **10 %** | 无出处（第 84 轮建模选择） |

结论：旧阈值高于「煎煮 1 小时的真实转化率」1.4~14 倍。开着它跑普通煎煮，
**所有糖苷水解产物会被判为「没跑到可检出程度」而全部消失**——这跟「文献产物必须都在」的
验收口径（AGENTS §11.8）直接冲突，也解释了为什么第 101 轮它必须被停用。

## 2. 改成什么

`conditions/kinetics.json`：

```json
"gates": {
  "extent_min": 0.0,        // 原 0.10，无出处 → 0.0，永久 no-op
  "extent_major": 0.5,      // 只影响 minor/major 标注
  "trace_below": 0.05       // 新：痕量阈值，只影响标注
}
```

- **`extent_min = 0.0`**：即使有人把 `validation.gate_enabled` 打开，判据是 `e < 0.0`，
  没有任何产物会被删。这是「不能用未标定的参数删产物」的结构性保证，不是靠注释提醒。
- **`trace_below = 0.05`**：取 7 个已发表数据集、26 个时间点里**最小的非零转化率 0.059**
  （Rb1 105 °C / 360 min），向下取整到 0.05。含义是「低于文献能观测到的量」，标 `none`（痕量），
  产物照旧保留。
- 两条都登记在新增的 `gates_provenance` 里（`status`：`removed_no_source` / `derived_from_dataset`），
  与 `template_provenance`、`constants_provenance` 同一套做法。

## 3. 语义变化（会给用户看的）

| extent | 旧标注 | 新标注 |
|---|---|---|
| < 0.05 | `none`（且被删） | `none` = **痕量**，保留 |
| 0.05 ~ 0.5 | `minor` | `minor` = 少量 |
| ≥ 0.5 | `major` | `major` = 主要 |

`core/reaction_paths.py` 的中文映射同步从「几乎不发生」改成「痕量」——
旧措辞会让人以为引擎在断言「这个反应不发生」，而它其实只是「进度低于文献能测到的量」。

## 4. 新增断言（防回退）

`tools/test_condition_extent.py` 增加 5 条，总数 54 → **59 条 ALL PASS**：

1. `extent_min == 0.0` 且 `gates_provenance.extent_min.status == "removed_no_source"`；
2. `trace_below == 0.05` 且 `status == "derived_from_dataset"`；
3. `trace_below ≤ min_documented_conversion()`（新增函数，直接读 `kinetics_measurements.json`）；
4. `extent_min ≤ min_documented_conversion()` —— **门控不可能删掉文献报告过的产物**；
5. 档位边界改为 `trace_below`（0.05 处是 `minor`，0.0 处是 `none`）。

第 4 条是这次的关键：以后谁想调高 `extent_min`，测试会先失败。

## 6. 还没做

1. `extent_major = 0.5` 仍是建模选择（只影响标签，不影响产物）。
2. `trace_below` 的 0.059 来自**人参皂苷一个体系**，其它反应族的最小可观测转化率可能不同；
   等有更多数据集后再按族细化。
3. 条件层真正参与产物生成（而非只做标注）仍需要「按族的转化率-条件模型 + 文献标定」，
   这条路本轮没有推进。

## 8. 外部依据核实（2026-11-06，用户要求）

核实两条可能被误用的「报告阈值」惯例，结论写进 `conditions/kinetics.json` 的
`gates_provenance.trace_below.external_checks`。

### 8.1 ICH Q3A(R2)：报告阈值 0.05 % —— 核实存在，但**不适用**

- 原文口径（多源一致）：原料药最大日剂量 ≤ 2 g/day 时，报告阈值 **0.05 %**、鉴定阈值 0.10 % 或 1.0 mg/day、界定阈值 0.15 % 或 1.0 mg/day；>2 g/day 时分别为 0.03 % / 0.05 % / 0.05 %。
- 分母是**原料药质量**，描述「杂质达到多少要报告」；我们的分母是**反应进度**（转化率）。对象不同，不能互相引用。
- 因此 `verdict: not_applicable`。数值 0.05 的巧合**不作为依据**。
- 来源：[IJPSR 综述（ICH Q3A/Q3B 阈值表）](https://ijpsr.com/bft-article/genotoxic-impurities-in-small-molecule-drug-substances-identification-risk-assessment-and-control-strategies?view=fulltext)、[PDA 杂质界定资料（Q3A(R2) 阈值表）](https://pda.org/docs/default-source/website-document-library/chapters/newsletters/metro/qualification-of-impurities-in-drug-substances-and-drug-products.pdf)

### 8.2 动力学「初速率取点」惯例 —— 存在，但**没有统一标准**

- 文献里常见的取点上限：1–2 %、5 %、10 %、20 % 都有人用；Halling 2020 建议「取到至少 10 % 转化率」以保证速率估计精度。
- 这是**做动力学实验时怎么取点**的建议，不是「低于多少就不该报告产物」。而且它本身不统一。
- 因此 `verdict: no_single_standard`。
- 来源：[Sci Rep 2023（初速率与转化率范围讨论）](https://pmc.ncbi.nlm.nih.gov/articles/PMC10497622)、[Halling 2020（初速率估计与取点）](https://pureportal.strath.ac.uk/files/99754042/Halling_BB_2020_Estimation_of_initial_rate_from_discontinuous_progress_data.pdf)

### 8.3 结论

`trace_below = 0.05` **维持「数据导出」地位**，不升格为文献依据；`extent_major = 0.5` 仍是
`unvalidated_model_choice`。这比「找一个看起来像的 0.05 %」诚实：两条惯例都核实过，
但都不适用，理由已落库。
