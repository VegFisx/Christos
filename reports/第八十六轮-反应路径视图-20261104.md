# 第八十六轮：产物产生路径的显示（2026-11-04）

## 0. 一句话

软件里原来**没有任何地方显示"这个产物是怎么变来的"**；数据其实一直在台账里（每一跳一行），
这轮把台账还原成**反应链**并显示在一页报告里，随 GUI 一键可达，另给一个离线 CLI。

口径按用户 2026-11-04 的定义（m00873）：**路径 = 煎煮/炮制等过程化学的反应链，不是生化合成路线。**

## 1. 先回答「有没有」

| 位置 | 原来显示什么 | 结论 |
|---|---|---|
| `ui_page.html` 结果区 | 只有「产物 N 个 · 出处 M 条」两个计数 | 没有路径 |
| `ui_page.html` 链接区 | 一页报告 / 台账 CSV / 索引 TSV | 没有路径 |
| 一页报告（`tools/make_report.py`） | 产物表 + 结构查看器 | 没有路径 |
| 台账 CSV | `product_smiles, source_smiles, rule_name, round, activation, activation_why, direction_cn, extent, co_products …` | **每一跳都在，但没人把它连起来** |

也就是说：缺的不是数据，是还原。`core/query_base.py` 的 `PATH_FIELDS` 本来就把
「哪个规则、第几轮、作用于哪对底物」逐行落盘，`Inventory.index()` 也已经在内存里按产物汇总过
`sources → paths`，只是这些信息从来没进过任何界面。

## 2. 做了什么

### 2.1 新增 `core/reaction_paths.py`（纯计算，约 280 行）

- `load_hops(csv)`：台账 → `Hop` 列表（一个 `Hop` = 一跳 = 一个规则作用在一对底物上）。
- `build_index(hops)`：底物 → 包含它的跳；`chains(target, index, seeds=…)`：从产物**往回** DFS，
  走到「没有上游」或命中输入成分即为一条完整链，`visited` 防环，返回时间正序。
- `render_chain(s)`：渲染成
  `C54H92O23 --[糖苷水解 · 第1轮]--> C42H72O13 --[糖苷水解 · 第2轮]--> …`，括号里带条件分/方向档。
- `formula_of(smiles)` / `looks_like_smiles(s)`：中间体没有名字，用分子式当标签；
  另外修掉「输入是 SMILES 时，名字字段其实就是 SMILES」导致标签变成 `C=C(CCC…` 的老问题。

### 2.2 一页报告里加了「反应路径」区块（`tools/make_report.py`）

- 产物表新增第 10 列 **「来路」** 按钮：点一下就把该产物的链展开在下方。
- 报告里新增下拉框：每个产物一项，文本是「分子式 · N 条 · 最少 N 轮」。
- 链的渲染在前端做（报告内嵌 `HOPS` JSON + 二十行 JS），**报告仍是单文件、可离线打开**，
  893 跳的报告 1658 KB。
- `make_report.py` 对 `reaction_paths` 是**软依赖**：import 失败只 warn，报告照常生成
  （不让这个新功能把主流程拖死）。

### 2.3 离线 CLI `tools/dump_paths.py`

```
python tools\dump_paths.py <输出目录或台账.csv> [--smiles 结构] [--all] [--max-chains 8]
python tools\dump_paths.py <输出目录> -o paths.json --csv paths.csv
```

默认只列 ≥2 跳的产物（单跳的"路径"没有信息量），`--all` 才全列。

### 2.4 GUI 里的提示

`ui_page.html` 结果区链接下面加了一句指路：想看某产物怎么变来的，去一页报告点「来路」，
或者在报告下方下拉框选它；也可离线跑 `dump_paths.py`。

## 4. 这一层**不是**什么（写清楚，免得以后误用）

1. **不是反应机理推箭头**：链上只写"哪个规则让哪个底物变成了哪个产物"，没有电子转移。
2. **不是概率路径**：没有"这个产物有 62% 走这条线"这种权重；多条链只按轮次和跳数排序。
3. **不是生化合成路线**：走的是煎煮/炮制条件下的化学反应规则，不是酶/基因通路。
4. **中间体不复用**：引擎每轮把新分子并进底物池再枚举，路径回溯是**事后还原**，
   不代表引擎"沿着这条链优化过"。
5. **立体/异构不区分**：引擎本身不做立体化学，链上同一个分子式可能对应多个异构体。
6. **辅料只在能显示的地方显示**：酯化那类双底物规则，乙酸会出现在链上；
   单底物规则里辅料仍不可见（这是第 84 轮记录的 P2 局限）。

## 5. 下一步：与文献对照（用户要的"产物一致 + 路径一致"）

建议分两步，先产物后路径：

- **产物层**：拿炮制/煎煮文献里点名的转化（如 Rb1→Rg3、甘草酸→甘草次酸）做靶子，
  判据 = 分子式 + 关键骨架命中，逐条记「命中 / 缺规则 / 规则在但没触发」。
- **路径层**：对每个命中的产物，比「链上的中间体是否出现在文献里」。
  文献常只给终产物，所以路径层只能对少数有中间体报道的案例做，**样本会很小，要如实说清**。

对照结果我会按「一致 / 部分一致（产物对、中间体对不上）/ 不一致」三档记账，不合并成百分比。
