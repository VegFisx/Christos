A. 修「脱水」——让伯醇也能脱水成端烯
================================================================================================

  【旧 [CH2:1][CH1:2]】[CH2:1][CH1:2][OH:3]>>[C:1]=[C:2].[OH2]
    ✗ 乙醇（伯醇）               (无)
    ✗ 1-丙醇                 (无)
    ✗ 2-丙醇                 (无)
    ✓ 2-丁醇                 ['CC=CC + O']
    ✗ 叔丁醇（应无α-H）           (无)
    ✓ 环己醇                  ['C1=CCCCC1 + O']

  【新 [CX4:1][CX4:2]】[CX4:1][CX4:2][OX2H:3]>>[C:1]=[C:2].[OH2]
    ✓ 乙醇（伯醇）               ['C=C + O']
    ✓ 1-丙醇                 ['C=CC + O']
    ✓ 2-丙醇                 ['C=CC + O']
    ✓ 2-丁醇                 ['C=CCC + O']
    ✓ 叔丁醇（应无α-H）           ['C=C(C)C + O']
    ✓ 环己醇                  ['C1=CCCCC1 + O']

  化学依据：醇脱水成烯，伯醇给端烯（乙醇→乙烯），仲醇给内烯（2-丁醇→2-丁烯），
            叔醇无 α-H 不能脱水。原来的写法只认「CH2 邻 CH(OH)」这一种。

  [修] 脱水 → [CX4:1][CX4:2][OX2H:3]>>[C:1]=[C:2].[OH2]
