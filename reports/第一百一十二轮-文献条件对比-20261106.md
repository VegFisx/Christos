# 第一百一十二轮：炮制辅料可选 + 文献条件 vs 预设档的产物对比

**一句话**：辅料现在可以自选（蜂蜜/黄酒/米醋/盐水/姜汁）；但拿文献条件重跑后，
**6 个案例的产物与预设档完全相同** —— 换条件只改台账里记的数值，不改化学。

---

## 1. 辅料可选（本轮新增）

### 1.1 命令行

```powershell
--paozhi-adjuvant-kind  auto|none|honey|wine|vinegar|salt|ginger
```

- `auto`（默认）= 旧行为，按工艺名查 `rules/paozhi_adjuvants.json`
- `none` = 不加任何辅料
- 其余 → 映射成工艺名（honey→蜜炙、wine→酒炙、vinegar→醋炙、salt→盐炙、ginger→姜炙）再查同一张表

结构全部来自 `tcm.db` 只读快照，未手写 SMILES。加载时会打印：

```
[辅料] vinegar → 醋（1 个共底物）
[辅料] honey → 蜂蜜（2 个共底物）
```

### 1.2 界面

主表单与方剂表单的「自定义条件」面板各新增一个「辅料」下拉
（自动 / 不加 / 蜂蜜 / 黄酒 / 米醋 / 食盐 / 生姜汁），
POST 字段 `paozhi_adjuvant_kind`，`ui.py` 转成 `--paozhi-adjuvant-kind`。

### 1.3 实测（甘草 limit 6、1 轮、炮制严格模式）

| 档 | 辅料 | 产物 |
|---|---|---|
| 炮制·自定义 | 不加 | 43 |
| 炮制·自定义 | 蜂蜜 | **46** |
| 炮制·自定义 | 米醋 | **81**（其中 39 条乙酸酯） |

→ **辅料确实改变化学**，这部分是有效的。

## 2. 文献条件 vs 预设档：产物对比

除条件外完全一致（同种子、1 轮、只跑 11 条炮制证据规则、`use_base_templates=False`）。

## 3. 为什么一模一样（做了对照实验）

把醋炙狼毒的种子单独抽出来，只跑「水 / pH 1.6」、不加辅料，温度分别设 **25 / 160 / 400 °C**：

```
25  °C -> 8 paths, 8 products
160 °C -> 8 paths, 8 products
400 °C -> 8 paths, 8 products
```

**25 °C 和 400 °C 的产物集合完全相同。** 原因两条，都是已知缺口：

1. **激活判据放行**：11 条炮制证据规则没有 ORD 条件窗口，`cond_activation` 走的是
   「无 ORD 条件数据，放行」分支（第 84 轮就记录过）。所以温度/时间/pH 不参与判零。
2. **extent 门控已停用**：第 101 轮按 AGENTS §十二，未标定参数不得判零，
   `conditions/kinetics.json` 的 `validation.gate_enabled=false` → `extent_gate` 恒 False。
   第 101 轮之前的实测是「煎煮 5 min 406 / 60 min 558 / 1440 min 705」，那个灵敏度现在被关掉了。

即：**换文献条件只会改台账里记的数值，不会改产物。**

---

## 4. 这轮结论对判据的意义

- 之前的假设是「炮制不准确是因为条件抄错了」。这轮把它**证伪**：
  醋炙从 84 °C 换到 160 °C / pH 1.6 / 40 min，产物一个不差。
- 真正的瓶颈在**规则/模板覆盖**（缺哪条转化）和**取样**（整味药只取 12 个成分），
  不在条件数值 —— 这与第 109 轮「取样层决定成败」、第 98 轮「缺产物归因」一致。
- 条件层要真正起作用，只有两条路：
  1. **标定 extent**：需要「时间 → 转化率」的文献数据（B1 提案，目前还没找到 3~5 条可用数据集）；
  2. **给证据规则写文献温度/pH 窗口**：需要文献给出「某温度下这类反应才发生」的证据，
     现有炮制文献基本只报产物、不报动力学，暂时拿不到。

## 6. 还没做

1. **文献条件只覆盖 6 个案例**；若要扩，需要每条都有一手文献给出条件值（当前 4 条是二手/借用工况）。
2. **辅料剂量未建模**：蜂蜜 12.5%、米醋 20% 这些用量对产物的影响，系统只按「有/无」处理。
3. **温度窗口的来源仍是建模选择**（`conditions/kinetics.json` 的 `gate_low_tolerance_C=30`、`hot_ceiling_C=400`），
   没有文献标定，因此不会因为「160 °C」或「84 °C」改变结果。
