| 产物 | 化学意义 |

**而且注意乌头原碱在【第 4 轮】出现** ——

## 5. ★ 我自己的验证脚本错了两次（都报的是假警报）★

### 假警报一：用错了视图

第一次审查我看到：

```
Top-20 覆盖: 脱水 15 / 酚氧化成醌 4 / 醛氧化 1
```

以为 **多样性排序坏了**。其实我调的是 `diverse_products`（**按分子式去重**），
而 CLI 用的是 `diverse_ranking`（**多样性排序**）。

**换成真视图后：单一规则最多 2 条。排序没问题。**

### 假警报二：手写复杂天然产物的 SMILES

我用自己敲的 SMILES 去找甘草次酸/乌头原碱，结果报：

```
— 甘草次酸         未出现
— 乌头原碱         未出现
```

**看起来像重大缺失。** 但改用**分子式**核对后：

```
✓ 甘草次酸   C30H46O4    11 个
✓ 乌头原碱   C25H41NO9    3 个
```

**是我把五环三萜和二萜生物碱的骨架敲错了。引擎一直是对的。**

> **手写复杂天然产物 SMILES 不现实。** 核对已知产物要用分子式或数据库里的真名。
