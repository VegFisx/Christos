## 1 规则

| 字段 | 内容 |
|---|---|
| id | `acylation_sulfonamide_001` |
| 反应 | 酰氯 + 芳基磺酰胺 → N-酰基磺酰胺 + HCl |
| SMARTS | 酰氯 `[C:4]-C(=O)Cl` + `[#16]-[NH]-[c]`；主产物 N-酰基磺酰胺，`byproducts: HCl` |
| 条件档 | `ambient` |
| provenance | `cited` |

### 1.1 依据

- 《N-取代磺酰胺类化合物的合成研究进展》，浙江化工 2012(4)：综述 N-取代/N-酰基磺酰胺的合成路线。
- *Recent advances in the synthesis of N-acyl sulfonamides*（PMC12416362，2025）：酰氯法合成 N-酰基磺酰胺的专门综述；碱（吡啶/Et₃N/NaHCO₃）条件下进行。

### 1.2 模板来源

用 N-甲基苯磺酰胺 + 乙酰氯标准例经 RXNMapper+RDChiral 派生；
把酰基上的甲基约束泛化为 `[C:4]`，以覆盖异丁酰氯等底物。
**没有用外部探针案例拟合模板**；295 中的 1 条只作 held-out 验证。
