## 3. 本轮补的：源码快照 + 哈希校验 + 一键还原

不依赖任何工具，`0.5 MB`，1 秒完成。

```
snapshots\
├── TCMAI-src-20261010-191318\     100 个文件，0.50 MB
│   ├── src\  scripts\  docs\github_upload\...
│   └── _MANIFEST.json             每个文件的 SHA256

```

**已校验完整可还原：**

```
文件数  : 100
总大小  : 0.50 MB
✓ 全部 100 个文件哈希一致，快照完整可还原
```

**还原脚本默认只演练、不写入**（实测）：

```
快照: ...\TCMAI-src-20261010-191318
文件数: 100
  一致 100 | 不同/缺失 0 | 快照自身缺文件 0

（演练模式，未写入任何文件）
```

> 为什么默认不写入：参考第 6 轮的教训——
> **一个会改数据的工具，默认就动手很容易把好东西改坏**
> （那次推导器覆盖坏了美拉德简化）。要真还原必须显式 `--apply`，
> 而且 `--apply` 会先把当前状态另存一份。
