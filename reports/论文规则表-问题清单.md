## 一、原子不守恒：产物里少了东西

### 1. β-酮酸脱羧 —— CO₂ 根本没写

```
论文 SMARTS: [CX3:1](=[OX1:2])[CX4:3][CX3:4](=[OX1:5])[OH:6]>>[CX3:1](=[OX1:2])[CX4:3]
                                                                      ↑ 到这里就结束了

底物：乙酰乙酸 CC(=O)CC(=O)O
论文版跑出来 →  CC(C)=O [C3H6O]                      ← CO₂ 呢？
现行版跑出来 →  CC(C)=O [C3H6O] + O=C=O [CO2]        ✓
```

**说明里写着"脱羧"，产物里却没有 CO₂。** 等于把 1 个碳和 2 个氧凭空扔掉。

### 2. 缩醛水解 —— 丢了一个醇

```
论文 SMARTS: ...>>[CX3H1:1]=[OX1:2].[OH:4][#6:5]
                                      ↑ 只写了一个醇

底物：苯甲醛二甲缩醛 COC(OC)c1ccccc1
论文版跑出来 →  O=Cc1ccccc1 [C7H6O] + CO [CH4O]            ← 只有一个甲醇
现行版跑出来 →  O=Cc1ccccc1 [C7H6O] + CO [CH4O] + CO [CH4O] ✓
```

**缩醛 R-CH(OR')(OR'') 水解应给醛 + 两个醇，论文版只写了一个。**

## 二、产物结构错：原子数对得上，结构不对

> 这一类**四道闸门全都发现不了**——原子守恒、价态、立体化学、化学合理性一路放行。

### 3. 醌还原 —— 产物没芳香化，分子式多 2 个氢

```
论文 SMARTS: [O:1]=[C:2][C:3]=[O:4]>>[OH:1][C:2][C:3][OH:4]

底物：邻苯醌 O=C1C=CC=CC1=O   [C6H4O2]
论文版跑出来 →  OC1C=CC=CC1O [C6H8O2]     ← 环己二烯二醇，非芳香
现行版跑出来 →  Oc1ccccc1O   [C6H6O2]     ✓ 邻苯二酚
```

碳氧双键变单键后，两个碳各补 1 个氢 —— **产物变成了非芳香的二醇，而说明写的是"邻苯二酚"。**

### 4. α,β-不饱和羰基水合 —— 加成方向反了

```
论文 SMARTS: [C:1]=[C:2][C:3]=[O:4]>>[C:1][C:2]([OH])[C:3]=[O:4]
                                            ↑ 羟基因在 α碳

底物：丙烯醛 CH2=CH-CHO
论文版跑出来 →  CC(O)C=O [C3H6O2]   ← 乳醛（α-加成）
现行版跑出来 →  O=CCCO   [C3H6O2]   ✓ 3-羟基丙醛（β-加成）
```

**α,β-不饱和羰基水合是 Michael 型加成，水应加到 β碳。**
两个产物分子式完全相同，只有连接方式不同。

## 三、整类底物漏匹配：最严重的一类

> 这类错误**不报错、不告警、配平也没问题**，只是**安静地漏掉一整类底物**。

### 5. 糖苷水解 —— 对所有酚苷无效

```
论文 SMARTS: [C:1]1(...)[O:7][C:8]
                              ↑ [C] 在 SMARTS 里专指【脂肪碳】

底物：水杨苷（酚苷）
论文版跑出来 →  (不匹配 / 无产物)
现行版跑出来 →  葡萄糖 + 水杨醇  ✓
```

**中药里的糖苷绝大多数是酚苷**（黄酮苷、酚酸苷……）。
苷元碳是芳香碳，`[C:8]` 匹配不上。

> **这条规则对最常见的糖苷类型完全无效。**

### 6-7. 酯水解 / 酰胺水解 —— 同样的 `[C:]` 问题

| 规则 | 论文写法 | 漏掉的底物 |
|---|---|---|
| 酯水解 | `[O:3][C:4]` | **酚酯**（乙酸苯酯跑不出产物） |
| 酰胺水解 | `[N:3][C:4]` | **伯酰胺**（乙酰胺跑不出产物）；N-芳基酰胺也不匹配 |

修法都是 `[C:]` → `[#6:]`（任意碳）。

> **记忆点：**
> `[C]` = 只脂肪碳 `[c]` = 只芳香碳 **`[#6]` = 任意碳**

## 四、过窄 / 过宽

### 8. 脱水 —— 乙醇匹配不上

```
论文 SMARTS: [CH2:1][CH1:2][OH:3]
              ↑ 邻碳恰好 2 个氢    ↑ 羟基碳恰好 1 个氢

底物：乙醇 CH3CH2OH  → 两个条件都不满足 → 无产物
      2-丁醇         → 满足 → 有产物
```

**乙醇脱水成乙烯是脱水最基础的例子，论文版做不到。**

### 9. 酮-烯醇化 —— 丙酮匹配不上

```
论文 SMARTS: [CX3:1](=[OX1:2])[CX4H2:3]   ← 要求 α碳恰好 2 个氢
底物：丙酮 CH3-CO-CH3 → α碳是 CH3 → 无产物
```

### 10. 脱甲基 —— 命中一切 O-CH₃，抢了别的规则的活

```
论文 SMARTS: [O:1][CH3:2]>>[O:1][H].[CH3][OH]

底物：乙酸甲酯 COC(C)=O    → 论文版也「脱甲基」→ 乙酸 + 甲醇
      甲基葡萄糖苷          → 论文版也「脱甲基」→ 葡萄糖 + 甲醇
```

**那些其实是【酯水解】【糖苷水解】该干的事。**
同一转化被两条规则重复计算，**产物的"由哪条规则产生"会指错**。

## 五、写法问题（不影响行为，但映射不对）

| 规则 | 论文写法 | 问题 |
|---|---|---|
| 酰胺水解 | 产物 `.[C:1](=[O:2])[O:3][H]` | 借用了酰胺氧的编号 `O:3` 当羟基氧 |
| 胺氧化 | 产物 `.[NH3]`、`[CX3H1:1]=[O:2]` | 氨没写映射；映射号给了元素符号 |

## 六、对论文结论的影响（诚实评估）

| 问题 | 是否影响产物列表 | 说明 |
|---|---|---|
| β-酮酸脱羧缺 CO₂ | **不影响主产物** | CO₂ 本就会被当作小分子副产物剔除；影响的是质量平衡 |
| 缩醛水解缺一个醇 | **影响** | 少了一个醇分子 |
| 醌还原产物错 | **影响** | 分子式不同（C6H8O2 vs C6H6O2） |
| 烯酮水合方向反 | **影响** | 产物是同分异构体，不是同一个分子 |
| 糖苷水解漏酚苷 | **影响较大** | 黄酮苷等一整类没被水解 |
| 酯水解漏酚酯 | **影响** | 酚酸酯类没被水解 |
| 酰胺水解漏伯酰胺 | **影响** | 氨基酸酰胺等没被水解 |
| 脱水 / 酮-烯醇化过窄 | **影响** | 小分子醇/酮的产物缺失 |
| 脱甲基过宽 | **影响溯源** | 产物所属规则标错 |

**总结：至少 8 条规则会改变产物列表的内容。**
