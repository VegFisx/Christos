醌还原：两个版本对各种醌的表现
====================================================================================================

【论文版（非芳香产物 + co=H2:2）】
   [O:1]=[C:2][C:3]=[O:4]>>[OH:1][C:2][C:3][OH:4]
   邻苯醌（苯醌型）                         底物 C6H4O2
        → OC1C=CC=CC1O [C6H8O2]
   对苯醌                              底物 C6H4O2
        → (不匹配)
   9,10-蒽醌（两个 C=O 不相邻）              底物 C14H8O2
        → (不匹配)
   1,2-萘醌（邻位）                       底物 C10H6O2
        → OC1C=Cc2ccccc2C1O [C10H10O2]
   丹参酮IIA 型（邻醌）                     底物 C14H10O3
        → (不匹配)
   大黄素（蒽醌，有酚羟基）                     底物 C15H10O6
        → (不匹配)

【我的版（芳香产物 + co=H2:1）】
   [O:1]=[C:2][C:3]=[O:4]>>[OH:1][c:2][c:3][OH:4]
   邻苯醌（苯醌型）                         底物 C6H4O2
        → Oc1ccccc1O [C6H6O2]
   对苯醌                              底物 C6H4O2
        → (不匹配)
   9,10-蒽醌（两个 C=O 不相邻）              底物 C14H8O2
        → (不匹配)
   1,2-萘醌（邻位）                       底物 C10H6O2
        → Oc1ccc2ccccc2c1O [C10H8O2]
   丹参酮IIA 型（邻醌）                     底物 C14H10O3
        → (不匹配)
   大黄素（蒽醌，有酚羟基）                     底物 C15H10O6
        → (不匹配)

====================================================================================================
判定：蒽醌类为什么匹配不上
====================================================================================================
  邻苯醌（苯醌型）                         反应物模板匹配位点 0
  对苯醌                              反应物模板匹配位点 0
  9,10-蒽醌（两个 C=O 不相邻）              反应物模板匹配位点 0
  1,2-萘醌（邻位）                       反应物模板匹配位点 0
  丹参酮IIA 型（邻醌）                     反应物模板匹配位点 0
  大黄素（蒽醌，有酚羟基）                     反应物模板匹配位点 0


  关键：新版的问题不在【反应物】模板（两边一样），而在【产物】模板——
        [c:2]/[c:3] 要求产物里那两个碳是芳香碳。
        对小环苯醌，RDKit 能把产物芳香化 → 成立。
        对蒽醌/萘醌等，RDKit 无法从产物模板直接推出芳香体系 → 匹配失败。

  结论：我的修法确实收窄了规则，丢了蒽醌类。
